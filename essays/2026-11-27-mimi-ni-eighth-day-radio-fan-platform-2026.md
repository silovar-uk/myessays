# なぜ芸能事務所は「8日目のラジオ」を配信するのか
## mimi-niから考える音声配信、権利、ファンとの直接的な関係

### 要旨

STARTO ENTERTAINMENTの無料音声サービスmimi-niは、既存ラジオ番組を放送から8日目以降に配信する。なぜすぐに配信しないのか。radikoとの配信時期の比較から、音楽の権利、番組の二次利用、顧客接点の保有、無料事業の収益性へと問いを広げる。Spotifyの先行機能終了を反証材料に、ファンビジネスの独自配信基盤が成立する条件を考察する。

## はじめに｜最速を競うはずのインターネットで、なぜ8日待つのか

インターネットのサービスは、たいてい速さを売りにする。配送は翌日、動画は同時配信、ニュースは速報。ところが、芸能事務所STARTO ENTERTAINMENTが運営する音声配信サービス「mimi-ni（ミミニ）」では、対象のラジオ番組を放送日から8日目以降に配信する。インターネットにしては、ずいぶん腰が据わっている。

なぜ8日なのか。この疑問を追うと、単なる聴き逃し配信の話が、放送局との関係や音楽の権利、芸能事務所がファンとの接点をどこまで自ら持つべきかという経営の話に変わる。

この記事は2026年11月27日時点の公開資料を対象とする。サービス開始からちょうど1年である。契約や収益の詳細は非公開または未確認のため、事実と考察を区別して進める。

## 守｜独自の音声配信基盤は、番組を聴く場所だけではない

2025年11月27日、STARTOは所属タレントのトークと音楽を楽しめる無料サービスを開始した。スマートフォン向けのウェブサービスで、専用アプリのダウンロードは不要。Apple、Google、LINE、Spotifyのアカウントでログインできる。第1弾はTravis Japanで、12月3日にレギュラー番組「Travis Japan の とらみみ」が始まった。

番組で紹介された曲はSpotifyやApple Musicなどと連携して楽しめる。お便り機能に加え、好きな場面を再生位置付きで共有する「推しどこシェア」もある。ラジオを聴いているうちに好きな曲が流れ、その場面を友人へ送る。番組の再生、楽曲との接触、ファンの反応が一つの利用体験として設計されている。

## 守｜ラジオとポッドキャストの違いは、時間と流通の主導権にある

1925年に日本でラジオ放送が始まった。従来のラジオは放送局が編成を決め、聴き手がその時間に合わせる仕組みである。2004年頃にはポッドキャストという名称が広まり、2005年にはAppleがiTunesで購読に対応した。日本では2010年にradikoが始まり、放送がインターネットでも聴けるようになった。

ポッドキャストは好きな時間に聴ける番組配信を指す。従来型の仕組みでは、更新情報と音声ファイルの所在を伝えるRSS（Really Simple Syndication）を使い、同じ番組を異なるアプリで購読できる。制作する会社と、聴取するためのアプリを運営する会社は別でもよい。ポッドキャストという言葉自体は、独自サイトでの配信だけを意味しない。

この歴史を踏まえると、mimi-niで重要なのは音声を配信することそのものではない。既に外部の配信先が存在するにもかかわらず、自社で企画・運営する聴取環境を用意したことである。

[ポッドキャストの歴史（イリノイ大学シカゴ校）](https://uic-library.github.io/Podcasting_Content/02-History/)／[radikoのサービス概要](https://radiko.jp/about)

## 守｜企業再編後のデジタル化と、音声市場の成長が背景にある

STARTOは旧ジャニーズ事務所の性加害問題を受けた組織再編の中で、2023年10月17日に設立された。2023年12月の発足発表では、従来サービスの継続に加え、デジタルによる事業変革（DX）、海外展開、メタバース市場への参入を掲げた。2024年4月に本格稼働した。

mimi-niはこのデジタル化方針と整合する取り組みと解釈できる。ただし、配信事業の開始は、被害者への補償や企業統治の改善が実現したことを意味しない。両者は別の評価軸で検証すべきである。

市場側にも背景がある。オトナルと朝日新聞社による2025年12月調査（2026年2月公表）では、国内の月間ポッドキャスト利用率は18.2％。15〜19歳では40.5％、20代では28.8％だった。ながら聴きが多い音声は、通勤や家事など、画面を注視しにくい時間にも接点をつくれる。

| 調査対象の年代 | 月間利用率 |
| --- | ---: |
| 全体 | 18.2% |
| 15〜19歳 | 40.5% |
| 20代 | 28.8% |

15〜19歳の利用率は全体の約2.23倍（40.5÷18.2）。ただし、この差は市場全体の年齢別利用状況であって、mimi-niの利用率やファンの年齢構成ではない。市場が若年層に浸透していることと、特定サービスが成功することは別問題である。

[STARTO発足発表](https://corporate.starto.jp/s/e/news/detail/10001)／[第6回ポッドキャスト国内利用実態調査](https://otonal.co.jp/news/50748)

## 守｜番組を持つことと、楽曲を自由に使えることは違う

芸能事務所はタレントの活動管理や出演企画を担い、レコード会社は録音音源の制作・販売・宣伝などを担う。ラジオ局は番組を制作・放送し、Spotifyなどのデジタル配信事業者（DSP）は楽曲を利用者へ届ける。実際の業務は企業によって重複するが、タレントとの契約があれば全楽曲を自由に利用できるわけではない。

| 用語 | 意味 |
| --- | --- |
| 著作権 | 作詞・作曲などの創作に関する権利 |
| 著作隣接権 | 実演家や音源製作者などの権利 |
| 原盤権 | 録音された音源に関する権利の通称 |
| 音楽出版社 | 楽曲の権利の管理・活用を担う企業 |
| JASRAC・NexTone | 楽曲の著作権管理事業者 |
| DSP | 楽曲などをデジタル配信する事業者 |

JASRACは、市販音源などを配信で利用する際には、著作権とは別に著作隣接権の許諾も必要だと説明している。外部音楽サービスとの連携は、独自に楽曲配信のすべてを担う必要を減らす設計と考えられる。ただしmimi-niの実際の契約、再生方式、料金の扱いまでは確認できていない。

音声ファイルが一つあれば話は終わり、というわけではない。ファイルの中に曲が入った瞬間、事業の関係者が増えるのである。

[JASRAC：音楽配信・音声配信の利用手続き](https://www.jasrac.or.jp/users/internet/audio/)

## 破｜8日目は、既存の放送流通との境界として読める

ここで冒頭の疑問に戻る。radikoの無料タイムフリーは放送後7日以内の番組が対象で、聴取開始後24時間以内、合計3時間までという制限がある。一方、mimi-niの対象ラジオ番組は8日目以降に無料配信される。

![放送日からの配信時期比較](https://silovar-uk.github.io/myessays/assets/mimi-ni-window-2026.svg)

*図1：公開仕様を基に筆者作成。対象番組・地域などの条件は各サービスで異なる。*

映画業界には、劇場、有料配信、テレビなどで公開時期をずらす「ウィンドウ戦略（Windowing strategy）」がある。流通先ごとの価値を守りながら、同じコンテンツを別の時期にも活用する発想だ。

mimi-niも無料タイムフリーとの競合を抑えながら番組を再利用する設計、と解釈できる。ただし、radikoには過去30日以内の番組を聴ける有料プランもあり、配信時期は一部重複する。8日目を選んだ契約上の理由は公表資料では確認できない。日付が一致するだけで、放送局と合意した条件まで分かったことにはならない。

## 破｜1番組から23番組への拡大は、既存資産の再利用によって進んだ

事業の歩みを時系列に並べると、新規番組を大量に制作して拡大したわけではないことが分かる。

| 時期 | 確認できた動き |
| --- | --- |
| 2025年11月27日 | サービス公開 |
| 2025年12月3日 | Travis Japanのレギュラー番組開始 |
| 2026年4月15日 | 既存ラジオ16番組を追加、全17番組へ |
| 2026年6月15日 | 木村拓哉 Flowなど4番組を追加 |
| 2026年7月15日 | 全23番組と発表 |
| 2026年10月1日 | 独自番組第2弾「EMOTIONAL STARS」開始 |

4月に追加された16番組は、既に放送局で放送されていた番組である。新規制作と異なり、番組企画や収録をすべて一から行わずに品ぞろえを増やせる可能性がある。もちろん、権利許諾、編集、配信などの追加費用は生じ得る。

同じ4月に番組横断のプレイリストと絞り込み検索が追加された点も見逃せない。番組を個別に再配信するだけなら、横断検索の価値は小さい。複数の番組をまとめて探し、聴く環境を整えることは、事務所単位の音声配信基盤としての価値を高める方向にある。

## 破｜独自配信の価値は、ファンとの関係を直接持てる点にある

従来のテレビ・ラジオ出演では、ファンとの接点の多くは放送局など外部の事業者を経由する。自社で運営するサービスなら、同意や適切なプライバシー管理を前提に、訪問頻度や番組の利用状況を自ら把握できる可能性がある。企業が顧客から直接取得する情報を、一次顧客データ（First-party data）という。

![外部配信と独自配信の接点比較](https://silovar-uk.github.io/myessays/assets/mimi-ni-contact-2026.svg)

*図2：接点の違いを表す概念図。実際のデータ共有契約を示したものではない。*

もう一つの仮説は無料サービスを有料ファンクラブの手前に置くことだ。SNSやテレビで知った人が音声を聴き、日常的に訪れるようになり、その後ファンクラブへの入会やライブ・グッズの購入につながる。マーケティングでは、購買に至るまでの入口をファネル上部（Top of funnel）と呼ぶ。

この仮説が成立するなら、mimi-niは音声広告の売上だけでは評価できない。ただし、他の顧客データとの連携、入会や購入への波及は未確認であり、実績と区別する必要がある。

## 破｜広告売上を試算すると、利用頻度の重要性が見えてくる

無料サービスでも、音声広告、番組スポンサー、企業タイアップ、有料コンテンツなどの直接収益は考えられる。ファンクラブやライブ、グッズ、楽曲の販売促進は間接的な価値の候補である。以下はmimi-niの実績ではなく、広告事業の仕組みを見るための仮想試算だ。

| 仮定 | 数値 |
| --- | ---: |
| 月間利用者（MAU） | 30万人 |
| 1人当たり月間再生数 | 8回 |
| 1再生当たり広告枠 | 2枠 |
| 広告千回当たり単価（CPM） | 1,500円 |
| 広告枠充足率 | 60% |

年間広告売上＝300,000×8×2×0.6÷1,000×1,500×12＝5,184万円。

同じ条件で月間平均再生数が4回なら2,592万円、16回なら1億368万円となる。利用頻度が半分になれば売上も半分になる。仮定値は市場平均でも実績でもなく、費用や広告代理店手数料も控除していない。

利用者数を増やすだけでなく、週ごとに聴きに来る習慣が広告枠の供給に結びつく。レギュラー番組は編成上の単位であると同時に、利用頻度を支える事業上の単位でもある。

## 破｜Spotifyが類似機能を終了した事実は、独自配信への反証になる

音楽とトークの組み合わせ自体は新しくない。Spotifyには「Music + Talk」という制作機能があったが、2024年7月に新規制作向けの提供が終了した。既存の公開済み番組は配信を継続する。

大手が撤退した機能を、別の会社が翌年に始めた。これだけでmimi-niの失敗を予測することはできない。Spotifyは幅広い利用者と制作者を対象とし、mimi-niは特定の芸能事務所の番組を中心にしているからだ。広範な市場で成立しなかった機能でも、強いファン需要を持つ限定市場では成立するかもしれない。

| 比較対象 | 主な強み |
| --- | --- |
| Spotify | 楽曲と番組の品ぞろえ、推薦 |
| radiko | 放送局とのネットワーク、聴き逃し |
| Voicy・stand.fm | 音声の発信・聴取環境 |
| YouTube | 検索・集客・共有 |
| mimi-ni | 特定タレントの番組と独自機能 |
| Weverse | ファン活動・購買・交流 |

利用者にとって、普段のアプリとは別にサービスへアクセスし、ログインする負担が増える。独自の管理権限を持ちたい企業と、余計な手間を省きたい利用者の利害は一致するとは限らない。独自配信の価値を証明するには、その負担を上回る番組や機能が必要になる。

[Spotify公式：制作ツールの変更](https://support.spotify.com/jp/creators/article/evolving-creation-tools/)／[radiko](https://radiko.jp/)／[Voicy](https://voicy.jp/)／[stand.fm](https://stand.fm/)／[Weverse](https://weverse.io/)

## 離｜総合型ファン基盤を目指すか、音声に集中するか

韓国の芸能企業HYBEが展開するWeverseは、コミュニティ、ライブ配信、グッズ販売などを組み合わせている。mimi-niは音声と音楽という特定の利用場面に集中している。比較すべきなのは規模だけではなく、ファンが何をするために訪れるかである。

特定の利用場面で顧客を獲得し、そこから隣接領域へ広げる方法を、くさび型の参入戦略（Wedge strategy）と呼ぶ。mimi-niが将来的にファン活動の総合基盤へ広がる可能性もある。ただし、そのような公式計画は確認できていない。音声に集中し続ける選択にも合理性があり得る。

スポーツクラブにも同様の問いがある。試合がない日に選手やOBの対談、試合の振り返り、クラブの歴史などを音声で届ければ、ファンとの接点を増やせる可能性がある。スポンサー提供番組への展開も考えられる。ただし、クラブ単位で配信基盤を開発するより、リーグ共通の基盤や既存サービスを利用する方が適切な場合もある。

応用する際には、「音声番組を始めるか」より先に、「何の顧客接点を増やしたいのか」「既存の配信先では何ができないのか」を明確にする必要がある。

[Weverse公式](https://weverse.io/)

## 実務｜成功を判断するなら、番組数よりも横断利用を調べたい

事業評価では、規模、習慣化、事業収益への波及を分けて計測する。

| 評価指標 | 確認すること |
| --- | --- |
| 月間利用者数（MAU） | 利用規模 |
| 日間利用者数／月間利用者数（DAU/MAU） | 日常的な利用 |
| 登録30日後の継続率 | 利用の定着 |
| 平均聴取時間・完聴率 | 番組への関与 |
| 番組横断聴取率 | 別の番組にも移るか |
| 顧客獲得費用（CAC） | 新規顧客1人当たりの獲得費用 |
| 顧客生涯価値（LTV） | 長期的にもたらす経済価値 |
| 番組制作・権利処理費用 | コンテンツ供給の経済性 |
| 購買転換率 | 他の事業への波及 |

とりわけ番組横断聴取率は、個別番組の集合から配信基盤へ進めているかを検証する指標になる。Snow Manを目的に訪れた人が他のグループの番組を聴くなら、事務所全体のファン育成につながる可能性がある。逆に、各利用者が一つの番組だけ聴く場合は、独自基盤を維持する価値を広告収益、顧客データ、権利条件など別の指標で検証する必要がある。

今後の追加調査では、利用者数・継続率、既存配信先との違い、利用者の不満、広告・スポンサーの実態、配信と楽曲の契約条件を優先したい。タレントの退所や活動休止、個人情報管理、海外での権利処理もリスクである。これらは現時点で確認されたサービス固有の欠陥ではなく、検証すべき論点である。

## 結論｜8日待つことは、流通を自分で設計することかもしれない

**空（事実）**：mimi-niは無料の独自音声サービスとして始まり、既存ラジオ番組の追加と横断機能によって拡大してきた。対象ラジオ番組は放送から8日目以降に配信される。

**雨（解釈）**：既存の放送流通を残しながら、自社でファンとの日常的な接点を持つ設計と考えられる。ただし、運営費を上回る価値が生まれているかは不明である。

**傘（提案）**：独自配信の必要性を判断する際は、広告売上だけでなく、利用継続、番組間の回遊、他の事業への波及、権利処理費用を測るべきである。

調べる前には、8日目という数字は単なる配信の遅れに見えた。放送局、楽曲の権利者、外部配信事業者、ファンの関係を並べてみると、それはコンテンツを誰が、いつ、どの場所で届けるかという事業の境界にも見えてくる。芸能事務所が音声配信を始めたこと以上に、その境界をどこに引くかが重要なのかもしれない。

## 付録｜他のエンターテインメント事業にも使える守破離リサーチ用プロンプト

以下は今回の調査手順を一般化した提案であり、STARTOの事業方針ではない。

```text
対象サービス：［URL・企業名］
目的：サービスの仕様を起点に、事業構造と成立条件を理解する。

1. 初期調査：公式資料・提供機能・価格・開始日・運営主体・市場史・権利関係を確認。
2. 構造化：顧客、提供価値、供給者、流通、収益、費用、競合に分ける。奇妙な仕様を一つ選ぶ。
3. 再調査：仕様と競合の対応関係、時系列、一次資料、反証事例を調べる。未確認は明記。
4. 守破離：守＝前提と具体的事実、破＝複数仮説と反証・試算、離＝異業種への応用。
5. 記事化：疑問から始め、具体と抽象を往復する。結論型見出しを使う。図表には出典と目的を付す。
6. 最終確認：事実・推論・提案を分け、数値と引用を検証。未検証の因果や意図を断定しない。
7. 実務化：成功条件を測るKPI、優先追加調査、空雨傘を提示する。
```

調査上の限界：mimi-ni本体への直接アクセスは403応答で制限された。公式発表、報道、radiko・Spotify・JASRACの公開資料を用いた。最新の総番組数、利用者数、収益、契約条件、実際の利用体験や利用者の批判は未確認。図の配信期間は公開仕様の比較であって、契約関係を証明するものではない。写真・告知画像は外部の掲載元を参照しており、転載許諾や将来の表示継続は確認していない。
