# 「装飾は犯罪」って、ほんまに“飾るな”という意味だったのか

デザイン史には、タイトルが強すぎて、本文を読む前に結論を知った気になる文章がある。

**Ornament and Crime.**

装飾と犯罪。

犯罪。

ちょっとボタンに影を付けただけなのに、警察が来そうである。

Adolf Loosのこの有名な論考は、20世紀のModernismやFunctionalismを語るとき、何度も引用されてきた。MoMAも1908年のessayとして紹介している。

では、Loosは本当に「飾るな」と言っていたのか。

ここでLoos本人の建築を見る。

Villa Müller。

外観はかなり抑制されている。

ところが内部は、素材、家具、空間の高低差、光の扱いが濃い。プラハ市立博物館もLoosの住宅について、ornament-free facadeを特徴として挙げる一方、drawing roomはsumptuousで、空間・material・equipment・lightを組み合わせた設計だと説明している。

外は静か。

中は豊か。

いきなり「装飾をなくせ」という覚え方が怪しくなってきた。

## VISUAL MAP｜装飾を「ある / ない」で見ない

まず、今日の見取り図を一枚にする。

```text
                 ORNAMENT
                    │
                    ▼
          何の仕事をしている？
                    │
      ┌─────────────┼─────────────┐
      │             │             │             │
   UTILITY      LEGIBILITY    EXPRESSION     IDENTITY
   使う助け      読む助け       感情を作る      らしさを作る
      │             │             │             │
   操作状態       区切り・階層      温度・祝祭感      ブランド記号
```

今日の問いは、

> 装飾は必要か？

ではない。

> **この装飾は、何の仕事をしている？**

である。

## FACT｜Loosは「装飾」を文化・経済・労働の問題として攻撃した

Loosの『Ornament and Crime』は、装飾を単なる見た目の好みとして扱っていない。

彼は、日用品に付け加えられるornamentを文化的発展、労働、製品寿命、経済の問題と結びつけ、近代社会では不要な装飾から離れるべきだと強く主張した。

MoMAのPaola Antonelliも、Loosの論考を、industrialization以後のデザインが過剰なexpressivenessやdecorationを抑制し、visual disciplineとfunctionalismへ向かった流れの代表例として位置づけている。

だから、

```text
ORNAMENT
↓
REMOVE IT
```

という読み方が生まれるのも分かる。

ただし、ここで止めるとLoos本人の建築と噛み合わない。

## もう一歩やりすぎる｜装飾を全部ゼロにしたLPを想像する

イベントLPを一つ考える。

最初はこう。

```text
🔥 炎日 🔥

[ EVENT PHOTO ]

SPECIAL MATCH
━━━━━━━━━━━━
限定フード
限定グッズ
イベント

[ チケットを購入 ]
```

では、「装飾は悪い」として徹底的に取る。

```text
炎日

写真

限定フード
限定グッズ
イベント

チケットを購入
```

かなり静かになった。

読みやすくなる部分もある。

でも、何かも消えた。

「祭りっぽさ」「特別な試合感」「この企画固有の温度」が弱くなっている。

今度は逆に、全部を飾る。

```text
🔥🔥 炎日 🔥🔥
✨ SPECIAL MATCH ✨
━━━━━━━━━━━━━━
★ 限定フード ★
★ 限定グッズ ★
★ イベント ★
🔥 [ チケットを購入 ] 🔥
━━━━━━━━━━━━━━
```

うるさい。

全部が叫んでいるので、どこが重要か分からない。

極端にすると分かる。

問題は「装飾があること」ではない。

**装飾の役割と配分が設計されていないこと**だ。

## Before → After｜「装飾を減らして」から一歩進める

### Before

> 装飾が多いので、もっとシンプルにしてください。

これは便利だけど、かなり危ない。

受け手は「消すこと」を目的にしてしまう。

### After

装飾を一個ずつ監査する。

```text
炎のモチーフ
→ EXPRESSION：企画の熱量を作る

色付きバッジ
→ LEGIBILITY：限定情報を識別する

ボタンの影
→ UTILITY：操作可能性を補助する？

独自パターン
→ IDENTITY：企画固有の視覚記号になる

キラキラ
→ ？？？
```

最後だけ説明できないなら、まずそこから疑う。

**Remove decoration by function, not by ideology.**

## RE-RESEARCH｜Loos本人の空間は、ぜんぜん「無味無臭」ではない

ここでVilla Müllerへ戻る。

プラハ市立博物館はこの住宅を、Loosの生涯にわたる住宅建築の探究を体現した重要作として紹介し、内部空間の構成、細部、material、equipment、lightを重視している。

さらに同館のLoos展資料では、Loosの住宅のdrawing roomはしばしばsumptuousで最大の部屋となり、libraryやboudoirはよりintimateに設計されたと説明されている。

つまり、

```text
FACADE
ornament-free / restrained

          ≠

EXPERIENCE
empty / emotionless
```

である。

装飾を抑制しても、素材、比例、空間、光、家具によってexperienceは豊かにできる。

これは現代UIにもそのまま持ち帰れる。

白背景にしたからminimalなのではない。

角丸を消したからfunctionalなのでもない。

**表現は、装飾パーツ以外からも生まれる。**

## ここでは笑えない｜『装飾と犯罪』には危険な前提もある

この論考を現代のデザイン原則として、そのまま持ち上げることはできない。

Loosはtattooを犯罪者や、当時の差別的な語彙で「退化」と結びつけた。MoMAはこの見方を明確にincorrectとし、tattooが持つ豊かな社会的・文化的歴史を無視したものだと批判している。

Canadian Centre for Architectureが所蔵するJuan José Lahuertaの研究紹介も、『Ornament and Crime』の語彙が当時のcriminal anthropologyやbioevolutionismと結びついており、女性、Papuans、artists、criminalsなどを「primitive / degenerate」とみなす疑似科学的な世界観を含んでいたと整理している。

ここは、

> 昔の人だから仕方ない

で流してはいけない。

**FACT:** この論考はModernist discourseに大きな影響を与えた。

**FACT:** 同時に、現在では受け入れられない人種主義的・疑似科学的前提を含んでいる。

**INTERPRETATION:** 現代の制作へ持ち帰るなら、「装飾は悪」という結論ではなく、追加した形式が何の価値を生んでいるかを検証する態度の方が使える。

## 現代UIへ戻す｜「Semantic Ornament」という見方

ここからは実務用のinterpretation。

`Semantic Ornament`を、この記事では**意味や役割を持った装飾**という作業用ラベルとして使う。

標準化された学術分類として使うのではない。

例えば、

```text
赤い縁取り
→ ERROR STATEを伝える

紙吹雪
→ 成功・祝福を演出する

クラブ固有の斜線パターン
→ IDENTITYを作る

カード間の罫線
→ GROUPINGを補助する
```

見た目としては全部「装飾」に見える。

でも、実際には情報や感情を運んでいる。

MoMAの『Talk to Me』が述べるように、現代のdesignではobjectやinterfaceは機能だけでなく、meaningやpersonalityも伝える。

すると、

```text
ORNAMENT
vs.
FUNCTION
```

という二択はかなり苦しくなる。

ときには、

```text
ORNAMENT
CAN BECOME
FUNCTION
```

だからだ。

## そのまま使える制作・修正指示

> 装飾要素を一律に削減するのではなく、それぞれがUTILITY、LEGIBILITY、EXPRESSION、IDENTITYのどの役割を担っているか確認してください。役割を説明できない要素から優先的に整理し、情報階層や操作性を妨げている装飾は弱めてください。一方、企画固有の感情やブランド性を担う表現まで均質化しないようにしてください。

短くするなら、これでいい。

> **この装飾は、何の仕事をしていますか？**

## #32 Memphisとの接続｜正反対に見えて、実は同じ問いをしている

#32ではMemphisを扱った。

Memphis側の問いは、

> Functionだけでdesignを説明できるのか？

だった。

今日のLoosからは、

> Expressionを足せば、それだけで豊かになるのか？

と問える。

並べるとこうなる。

```text
             LESS                         MORE
              │                            │
LOOS      不要な表現を疑う           意味ある素材・空間
              │                            │
MEMPHIS   機能だけを疑う             表現・文化・感情
              │                            │
              └───────────┬────────────────┘
                          ▼
                 WHAT IS IT DOING?
```

結局、どちらも「量」だけでは評価できない。

#32で増やしたEXPRESSIONという軸を、#41では監査する。

**Expression matters. And expression still needs a reason.**

## 30秒でできる観察｜一個だけ消してみる

今見ているWebサイトで、見た目の要素を一個選ぶ。

色、線、影、模様、角丸、背景画像、何でもいい。

頭の中で消す。

そして聞く。

```text
これを消す
   ↓
何が失われる？
```

「情報の区切り」ならLEGIBILITY。

「押せそうな感じ」ならUTILITY。

「楽しい感じ」ならEXPRESSION。

「このブランドらしさ」ならIDENTITY。

「特に何もない」なら、削れるかもしれない。

## 次につながる概念｜Ornament as Information

次に面白いのは、装飾をinformationとして扱うことだ。

模様、texture、color、motionは、単に画面を賑やかにするだけではない。

category、state、hierarchy、culture、brandを運ぶことがある。

そこで次は、

**どこからが情報で、どこからがノイズなのか。**

という問題につながる。

---

## 今日の中心命題

**Do not ask whether decoration is necessary. Ask what job it is doing.**

「装飾は必要か？」ではなく、

**「この装飾は何の仕事をしているか？」**

と聞く。

『装飾と犯罪』というタイトルだけ見ていたときは、Loosは「飾るな」と言っている人に見えた。

でも本人の建築を見て、内部空間を調べ、論考の危険な歴史的前提まで追うと、同じ言葉が少し違って見える。

装飾を消せばdesignが良くなるわけではない。

装飾を足せば豊かになるわけでもない。

そして装飾だと思っていたものが、実は情報や感情を運んでいることもある。

次に影や罫線や模様を見たとき、

「これは装飾だ」と分類する前に、たぶん一回だけ止まる。

**で、こいつは何の仕事をしてるんや。**

その瞬間、装飾は「ある / ない」の問題ではなくなる。
