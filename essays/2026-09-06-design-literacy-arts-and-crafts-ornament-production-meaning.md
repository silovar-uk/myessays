# Arts and Crafts――装飾は「余計」なのか。それとも仕事をしているのか
## Design Literacy #20｜Ornamentを量ではなく、役割と生産から読む

**Don’t ask whether something is decorative. Ask what work the decoration is doing.**

直前のDesign Literacy #19では、Progressive Disclosureを扱った。

そこで考えたのは、**何を今見せ、何を後から見せるか**というInformation Timingだった。

では、情報量を整理したあとに残る、模様、質感、イラスト、余韻、色の強さはどう考えればいいのか。

「なくても操作できるから削る」でいいのか。

今回は19世紀後半のArts and Crafts Movementを手掛かりに、**装飾を“ある／ない”ではなく、“何の仕事をしているか”で読む**。

## 1. まず一言：Decorationは存在ではなく、仕事で評価する

イベントカードを二つ想像する。

```text
A
┌─────────────────┐
│      SALE       │
│                 │
│    9.19 SAT     │
│                 │
│   BUY TICKET    │
└─────────────────┘
```

```text
B
╔═════════════════╗
║  /// 炎日 ///   ║
║                 ║
║    9.19 SAT     ║
║   pattern / heat║
║                 ║
║   BUY TICKET    ║
╚═════════════════╝
```

Bの方が装飾は多い。

でも、そこからすぐに、

```text
A = good
B = noisy
```

とは決められない。

見るべきなのは、

```text
そのpatternはイベントの性格を強めている？
情報階層を壊していない？
視線を邪魔していない？
ブランドの記憶を作っている？
制作コストに見合う仕事をしている？
```

という役割だ。

**More decoration does not automatically mean worse design.**

装飾の量と、デザインの質は同じ軸ではない。

## 2. 仕組み：Ornament Function Audit

「装飾を減らすべきか」を判断するとき、装飾を四つの仕事へ分けると使いやすい。

### 1. Meaning / Information

**意味を補っているか。**

たとえば区切り線、強調背景、方向を示す形、状態を補助するpattern。

単なる飾りに見えても、情報構造を伝えている場合がある。

### 2. Expression / Identity

**そのサービスらしさ、イベントらしさを作っているか。**

```text
texture
illustration
pattern
motion
typographic character
```

は、機能を直接増やさなくても、identityや期待される体験を作る。

### 3. Structure / Rhythm

**視線やリズムを整えているか。**

装飾的な反復、余白、罫線、色面が、sectionの切り替わりやattentionの強弱を作っていることがある。

### 4. Production / Material

**どう作られたか、何を作りやすく・作りにくくしているか。**

ここはArts and Craftsから強く学べる視点だ。

見た目だけでなく、

```text
誰が作る？
どんな道具で作る？
何回再利用する？
どのくらい修正可能？
制作する人にどんな負担がある？
```

まで含めて考える。

```text
Decorative?
→ Yes / No
```

ではなくなる。

```text
What does it do?
↓
Keep / Reduce / Redesign / Remove
```

になる。

## 3. Before → After：「ゴチャつくから削る」から、役割を診断するへ

### BEFORE

デザインレビューで、

> 「ちょっとゴチャついているので、装飾を減らしてください」

と伝える。

これだと、何を削るべきかの基準がない。

担当者は、

```text
patternを消す？
illustrationを小さくする？
borderをなくす？
色を減らす？
```

と推測するしかない。

### AFTER

まず役割を分類する。

```text
背景pattern
→ event identity

太いsection rule
→ information grouping

炎のillustration
→ attention / emotional tone

意味のない小さなsparkle × 18
→ role unclear
```

最後のものは削除候補。

前の三つは、「装飾だから」ではなく、それぞれの仕事と副作用を見て強度を調整する。

**Reduction should follow diagnosis.**

削る前に診断する。

## 4. そのまま使える制作・修正指示

制作指示なら、こう言える。

> **装飾を一律に減らすのではなく、各要素がMeaning / Expression / Structure / Productionのどの役割を担っているか整理してください。役割がない、または他要素と重複している装飾は削減し、役割があるものは可読性・操作性・制作コストを損なわない強度へ調整してください。**

レビューでは、まずこの一問。

> **「これを消すと、情報以外に何が失われますか？」**

もう一問足すなら、

> **「その価値は、作る・保つコストに見合っていますか？」**

これで、見た目だけでなくproductionまでレビュー対象になる。

## 5. 歴史との接続：Arts and Craftsは一つのstyleではない

V&Aは、Arts and Crafts Movementを19世紀後半のイギリスで、industrialisationの悪影響とdecorative artsの低い社会的位置づけへの反応から生まれた運動として説明している。

ただし、**一枚岩のstyleや一つの組織だったわけではない。**

V&Aによれば、MovementにはArts and Crafts Exhibition SocietyやArts Workers Guildなど複数のsociety、craftsperson、小規模workshopだけでなく、大きなmanufacturing companyまで含まれていた。

[Victoria and Albert Museum — Arts and Crafts: an introduction](https://www.vam.ac.uk/articles/arts-and-crafts-an-introduction)

William Morrisの影響は非常に大きい。

一方で、

```text
Arts and Crafts = Morris一人の思想
```

とすると、運動の幅が消える。

Metropolitan Museumも、Arts and Craftsは特定の一つのstyleを推進したのではなく、decorative designとindustrial labourをめぐるreformを志向したmovementとして整理している。

[The Metropolitan Museum of Art — The Arts and Crafts Movement in America](https://www.metmuseum.org/essays/the-arts-and-crafts-movement-in-america)

だから、ここで学ぶべきなのは「Arts and Crafts風の見た目」だけではない。

**How things are made can be a design question.**

何を作るかだけでなく、どう作るかまでdesignの問題になる。

## 6. Morrisは「機械を全部捨てろ」と言ったわけではない

ここは特に単純化しやすい。

```text
handmade = good
machine = bad
```

と覚えると分かりやすいが、史料とはずれる。

V&Aは、Morrisはmachineを全面的に否定していたわけではなく、とくにdivision of labourによって作り手と完成品の関係が切断されることを問題視したと説明している。

さらにMorris自身は1884年の**Useful Work versus Useless Toil**で、機械が本当に人間の負担を減らす社会なら、unattractive labourを減らすために活用できるという趣旨を論じている。

[William Morris — Useful Work versus Useless Toil, 1884](https://www.marxists.org/archive/morris/works/1884/useful.htm)

別の同時期の講演でも、Morrisは機械を人の「master」ではなく「servant」として使うという方向を述べている。

[William Morris — A Socialist's View of Art and Labour, 1884](https://www.marxists.org/archive/morris/works/1884/prestonart.htm)

つまり彼の批判の中心を、

```text
technologyそのもの
```

だけに置くより、

```text
technology
×
labour conditions
×
purpose of production
×
relationship to the maker
```

として読む方が資料に近い。

```text
template
component library
generative AI
automation
no-code
```

を見るときにも使える。

ただし、これはMorrisがAIやDesign Systemについて論じたという意味ではない。

**STRUCTURAL ANALOGYとして、production methodの評価軸を借りている。**

## 7. 誤解しやすい点：Craftは自動的に「みんなのため」になるわけではない

Arts and Craftsには、日常生活の中へ美しい、よく作られたものを戻そうという強い社会的理想があった。

しかし、ここには現実的な緊張もある。

Metropolitan Museumは、手仕事中心の制作は時間がかかり高価になり、well-designed objectsを広く届けるという理想と衝突したことを指摘している。

[The Metropolitan Museum of Art — Design, 1900–1925](https://www.metmuseum.org/essays/design-1900-25)

別のMetの解説でも、Morrisの手工芸品は高い製造コストによって多くの人には手が届きにくくなったという矛盾が整理されている。

[The Metropolitan Museum of Art — Design Reform](https://www.metmuseum.org/essays/design-reform)

ここが重要だ。

```text
careful craft
→ quality ↑
→ labour / time ↑
→ cost ↑
→ access ↓
```

となる可能性がある。

**Craft quality and social accessibility can conflict.**

丁寧に作ることと、多くの人に届けることは、常に同じ方向へ進むわけではない。

だから現代の制作でも、

```text
完全custom
vs
reusable component

handmade asset
vs
template

bespoke motion
vs
system motion
```

を「どちらが上質か」だけで決めない。

品質、労働、速度、保守性、価格、届く範囲のtrade-offを見る。

## 8. Morrisの「Useful / Beautiful」を、機能主義の標語にしない

Morrisの有名な1880年の言葉に、家に置くものについて、役に立つと分からないもの、美しいと信じられないものは持たない、という趣旨の助言がある。

V&Aもこの言葉をMorrisの1880年の発言として紹介している。

[Victoria and Albert Museum — Furnishing the aesthetic home](https://www.vam.ac.uk/articles/furnishing-the-aesthetic-home)

面白いのは、

```text
Useful OR Beautiful
```

であって、

```text
Useful ONLY
```

ではないことだ。

ここから「Morrisは機能がない装飾を否定した」と読むのは飛躍になる。

実際、Morrisのwallpaperやtextileには豊かなpatternがあり、V&Aは彼の自然由来のpatternが市場を拡大し、その後のArts and Crafts interiorsでもdecorative fabrics、wallpapers、rugsなどが広く用いられたと説明している。

[Victoria and Albert Museum — Pattern design after William Morris](https://www.vam.ac.uk/articles/pattern-design-after-william-morris)

つまり、

**Beauty itself can be part of what an object is for.**

という読みもできる。

ただし、これは今回の記事上のINTERPRETATIONであって、Morrisの一文から現代UXの定義を直接導くものではない。

## 9. 以前の学びとの接続：Information Density ≠ Expressive Density

#19 Progressive Disclosureでは、

```text
何を今見せる？
何を後で見せる？
```

を考えた。

これは主に**Information Density**を扱う。

今日、別の軸を足す。

```text
Information Density
= 判断・説明・選択肢がどれだけ見えているか

Expressive Density
= pattern・image・texture・type・motionなどが
  どれだけ体験の性格を作っているか
```

この二つは同じではない。

```text
情報を減らす
≠
表現を減らす
```

ということだ。

ここが今日の**前より解像度が上がる接続**。

たとえばProgressive Disclosureでadvanced settingsを閉じても、ブランドを作るillustrationやtextureまで消す必要はない。

逆に情報項目が少なくても、装飾がHierarchyを壊していれば減らすべきだ。

**Simplicity is not a single slider.**

「シンプルさ」は一つのつまみではない。

## 10. 30秒でできる観察：装飾を一個だけ監査する

好きなWebサイト、アプリ、ポスターを一つ開く。

装飾っぽい要素を一個だけ選ぶ。

そして四問。

```text
MEANING
これで何が分かる？

EXPRESSION
これで何を感じる？

STRUCTURE
これでどこを見る？

PRODUCTION
これを作り、維持するコストは？
```

最後に、

**「消したら何が失われる？」**

を考える。

何も失われないなら、削除候補。

何かが失われるなら、それは少なくとも何かの仕事をしている。

あとは、その仕事に対して強すぎないか、コストが高すぎないかを調整する。

## 11. 次につながる概念：Form follows function

次は、近代デザインで何度も現れる有名な言葉へ進める。

**Form follows function.**

ただし次回、いきなり、

```text
機能が大事
→ 装飾はいらない
```

とはしない。

先に問うべきなのは、

**What counts as function?**

だ。

```text
physical function
communication
recognition
emotion
identity
social function
maintenance
```

までfunctionに含めると、

```text
function vs ornament
```

という二択そのものが揺らぎ始める。

そこからModernismとOrnamentの議論へ進める。

---

**Today’s claim:**

**Don’t ask, “Is this decorative?” Ask, “What work is this decoration doing, and what does that work cost?”**

日本語なら、

**「これ、飾りだから消す？」ではなく、「この飾りは何の仕事をしていて、その仕事にどれだけコストがかかっている？」と聞く。**

Arts and Craftsから受け取れるのは、昔の植物柄だけではない。

**見た目・作り方・働き方・届き方を、一つのデザイン問題として見る視点**だ。
