# 棚なのに、棚以上のことを言いたがる――Memphisと「機能だけでは足りない」デザイン
## Design Literacy #32｜Functionalismの外側に、意味・感情・文化を足す

棚という家具は、かなり説明が終わっている。

板があって、物を置ける。

それで十分そうに見える。

ところが1981年、Ettore Sottsassがデザインした《Carlton》を見ると、棚が急に余計なことを始める。

斜めの棚。強い色。安価なプラスチック・ラミネート。中央には引き出し。全体はロボットにも、偶像にも、両手を広げた人にも見える。

棚なのに、棚であることに専念していない。

**なぜ、わざわざこんなことをするのか。**

「使いやすさ」がデザインの正義なら、これはだいぶ怪しい。

今回はそこを本気で調べる。

---

## 1. まずCarltonを『変な棚』として見る

The Metropolitan Museum of Artは《Carlton》を1981年のMemphisを代表する作品として所蔵している。

面白いのは、見た目が無秩序に見えるのに、内部にはかなり論理的な構造があることだ。

Metの解説では、表面の鮮やかさやランダムに見えるsolid / voidの組み合わせの下に、実際の正三角形と暗示された正三角形による構造があるとされる。さらに、斜めの棚も単なる嫌がらせではなく、本が倒れやすい垂直棚に対して機能的な側面を持つ。

ここで最初の認識が少し崩れる。

**変な形＝機能を捨てた形、ではなかった。**

むしろ、機能の上に別の仕事を載せている。

### FACT

- 《Carlton》はEttore Sottsassが1981年にデザインし、Memphis Milanoが製造したroom divider / bookcase / chest of drawersの複合家具である。
- MDFと比較的安価なplastic laminateを用いながら、高級市場向けに手仕事で製作された。
- 外観の背後には正三角形を基礎とした論理的な構造がある。

### INTERPRETATION

《Carlton》の面白さは「使いにくいものをわざと作った」ことより、**家具に実用性以外の意味を載せてもよい、と露骨に示したこと**にある。

---

## 2. Memphisは、どこから出てきたのか

Memphisだけを見ると、突然1980年代に世界がギザギザし始めたように見える。

でも、その前段がある。

The Metは、1960〜70年代のイタリアでArchizoom、Superstudio、Studio AlchimiaなどのRadical Design / Anti-Designの動きが、International Styleの純粋なfunctionalismへの反発として展開したと整理している。

SottsassもStudio Alchimiaに短く参加し、1979年には《The Structures Tremble》を制作している。Metはこの作品を、modernismのfunctionalismへ反発したAlchimiaの思想をよく示す例としている。

そして1981年、Sottsassを中心にMemphisが始まる。

名前の由来まで妙だ。

Metによれば、Sottsass宅で集まっていた際、Bob Dylanの「Stuck Inside of Mobile with the Memphis Blues Again」が流れていて、Memphisという言葉が、アメリカの都市、blues、郊外、古代エジプトの首都など複数の意味を同時に呼び起こすことから採用された。

すでに名前から一つに決める気がない。

---

## 3. 『機能を否定した』ではなく、『機能だけでは足りない』

ここは雑にするとMemphisがただの反抗期になる。

Sottsass自身は、キャリア初期に合理的・機能主義的な工業デザインを手がけていた。The Metは、彼がその後1960年代から、functionを超えてsymbolism、emotional appeal、global and historical referencesを持つ物へ関心を広げたと説明している。

つまり構図は、

```text
FUNCTION
↓
嫌いになる
↓
DECORATION
```

ではない。

むしろ、

```text
FUNCTION
+
SYMBOL
+
EMOTION
+
HISTORY
+
CULTURE
```

である。

Peter Shireの1981年《Two Tone Cone》についても、MetはMemphisの目標を、functional objectsにhistoric / symbolic meaningとemotional appealを持たせることとして説明している。

**Function answers “Can I use it?” Expression answers “What does it mean?”**

機能は「使えるか」に答える。

表現は「これは自分にとって何なのか」に答える。

---

## 4. やりすぎ調査：Carltonから『機能だけ』を残したらどうなるか

ここで一度、Carltonを頭の中で解体する。

残すのは、

- 本を置ける
- 空間を仕切れる
- 引き出しがある

だけ。

色を消す。

模様を消す。

斜めを消す。

象徴的なシルエットを消す。

歴史的引用も消す。

すると、たぶんかなり普通の収納家具になる。

**使える。**

問題ない。

では逆に、機能を全部消して色・柄・形だけ残す。

今度は家具というより彫刻へ近づく。

この極端な比較で見えるのは、Memphisが狙っていた場所がその中間だということだ。

```text
UTILITY ───────────── EXPRESSION
    ↑ Memphisはこの間を広げた
```

「役に立つ」と「意味がある」を同じ軸の両端に置く必要はない。

両方を持てる。

---

## 5. これをUIへ持ち込むと、急に危険になる

家具なら、多少変な棚でも眺めていられる。

UIにはタスクがある。

読む。

探す。

比較する。

入力する。

戻る。

買う。

ここでMemphisを表面だけ真似すると、事故る。

```text
ボタンを斜めにする
ナビゲーションを予想外の場所へ置く
文字を読みにくくする
操作ごとに違うルールを使う
```

これは「Postmodernだから自由」ではない。

単にoperabilityを削っている。

そこで、UIではレイヤーを分ける。

```text
STRUCTURE
情報階層・Navigation・操作

↓ まず守る

EXPRESSION
色・Typography・写真・形・Texture・Motion・Microcopy
```

**Do not break the information structure first. Break the expressive layer first.**

情報構造を最初に崩すのではなく、表現層から変える。

---

## 6. Before → After：全部きれいにしたら、全部同じになった

イベントページを考える。

### Before

```text
EVENT 01
9.19 SAT
SPECIAL MATCH
[ 詳細を見る ]

EVENT 02
12.13 SUN
SPECIAL MATCH
[ 詳細を見る ]
```

読みやすい。

構造も揃っている。

10件並べても迷わない。

でも、全部同じ顔をしている。

そこで構造は変えず、表現レイヤーだけ変える。

### After

```text
共通構造
DATE
TITLE
DESCRIPTION
CTA

企画A
Typography → 緊張感

企画B
Illustration → 祝祭感

企画C
Color / Texture → 季節感
```

ここで作りたいのは「バラバラ」ではない。

**同じ文法で、違う声を出すこと。**

これはDesign Systemとも対立しない。

むしろ、構造をsystem化しておくほど、どこを表現として変えてよいか明確になる。

---

## 7. そのまま使える制作・修正指示

> **情報階層と主要な操作方法は維持したまま、企画固有の感情・文化・ブランド性が伝わる表現レイヤーを追加してください。差別化のためにNavigationや操作規則を崩すのではなく、色・タイポグラフィ・写真・形状・パターン・モーションなど、理解を妨げない層から変化を作ってください。**

短く言うなら、

> **機能を崩すのではなく、意味を足してください。**

レビュー時には一問だけでいい。

**「この装飾は、何を伝えている？」**

答えが「なんとなく賑やかに」しか出てこないなら、まだsurfaceで止まっている。

---

## 8. 誤解しやすい点：Memphis＝三角・水玉・パステルではない

Memphis風のデザインを検索すると、幾何学模様、派手な配色、ギザギザ、水玉が大量に出てくる。

もちろん、それらは視覚的特徴の一部ではある。

しかし、それだけを真似すると思想が抜ける。

Met所蔵のGeorge Sowden《Penrose Fruit Bowl》は、古代ピラミッドにもrobotic deviceにも太陽にも見えると解説される。Peter Shire《Two Tone Cone》にはBauhausやWiener Werkstätteへの参照が見られる。Sottsassの器にはGreek / Roman glassや古代陶器への関心も現れる。

Memphisは「未来的で派手」だけではなく、**high / low、古代 / 現代、工業素材 / 手仕事、実用品 / 記号**を意図的に同居させた。

### FACT

Memphisでは鮮やかな色やpattern、plastic laminateなどが広く使われた。

### INTERPRETATION

だから現代制作で受け取るべきなのは「Memphis柄」より、**本来別々だと思っていた価値を一つの物の中へ共存させる態度**の方かもしれない。

---

## 9. Tschicholdと並べると、逆方向に見えて同じ問いになる

Design Literacy #29ではJan Tschicholdを扱った。

そこでは、

```text
RULE
WHY
CONDITION
EXCEPTION
```

という形で、ルールの適用条件を考えた。

Memphisはさらに一段前へ行く。

```text
Tschichold
「この問題には、どのRuleが適切か？」

Memphis
「そもそも、そのProblem Definitionで足りているか？」
```

「使いやすくする」という問題設定だけなら、表現は余計に見える。

でも問題を、

> 人は物を使うだけでなく、意味を読み、好き嫌いを持ち、文化や記憶と結び付ける

まで広げると、表現は急に仕事になる。

これが今回の、前より解像度が上がる接続だ。

**Ruleを疑う前に、Ruleが解こうとしているProblemを疑える。**

---

## 10. 30秒でできる観察：なくしても使えるのに、なくすと困るもの

好きなWebサイトやアプリを見る。

一つだけ探す。

**なくしても操作できるけど、なくしたら『らしさ』が減るもの。**

例えば、

- 写真のtone
- typeface
- corner radius
- icon style
- illustration
- motion
- microcopy

そして聞く。

```text
なくしても使える？
YES

なくすと意味・人格・期待が減る？
YES
```

なら、それはexpressive layerかもしれない。

次に、その表現が何を伝えているのか一文で説明する。

説明できなければ、装飾で止まっている可能性がある。

---

## 最後に：棚がこちらを見ている

最初、《Carlton》は変な棚に見えた。

派手で、斜めで、ずいぶん余計なことをしている。

でも調べた後では、少し違って見える。

内部には論理的な構造があり、斜めの棚にも機能があり、その上でcheap / luxury、ancient / contemporary、utility / symbolといった矛盾するものを同時に載せている。

だから《Carlton》は、機能を馬鹿にしている家具ではない。

むしろこちらへ、ずっと質問している家具なのかもしれない。

**「使える。それで、話は終わりなん？」**

UIでも同じだ。

迷わず操作できることは大前提。

そのうえで、全部を正しく整えた最後に残る。

**「で、これは誰のデザインなん？」**

そこからexpressionの仕事が始まる。

---

## 今日の中心命題

**Function tells us how to use something. Expression tells us why it feels like this thing.**

機能は「どう使うか」をつくる。

表現は「なぜ、これなのか」をつくる。
