# 「今・ここ・私」× Focus × Attentional Agency 制作ノート

Date: 2026-09-15
Target essay id: `focus-now-here-me-attentional-agency`

## 1. Research｜一次調査

### 出発点

元の仮説は「集中とは、今・ここ・私である」。ただし、集中していないこと自体を悪とせず、未来を考える、発想を広げる、メタ的に考えるときには意識の分散も必要とする。

問題意識は二つある。

1. 必要なときに集中モードへ入れるか。
2. アテンションエコノミーの環境で、注意の向きが自分の目的から他者の目的へ移るとき、それを自分で把握・選択できているか。

このため、「集中力が高い／低い」という能力論よりも、集中・分散・休息を自分で切り替えられるかという`attentional agency`の問題として調査した。

### 接続した理論・資料

1. Eric Hayot / Uneven U
   - *The Elements of Academic Style*で提示される、段落内の抽象度を上下させながら思考を進める構造を執筆原理に使用。
   - 単なる「主張→例→要約」ではなく、具体例を通過したことで段落末の認識が冒頭より高くなることを重視。
   - https://cup.columbia.edu/book/the-elements-of-academic-style/9780231168014/

2. Attentional Capture and Control
   - Theeuwes (2025)。注意制御をtop-down goals、bottom-up salience、selection historyの競合として整理。
   - 「見てしまう＝意志が弱い」という単純化を避ける根拠として使用。
   - https://pubmed.ncbi.nlm.nih.gov/39401852/

3. Mind Wandering
   - Smallwood & Schooler (2015)。mind wanderingはtask errorと関連する一方、creativityやfuture planningにも関わる。
   - 「集中していない＝失敗」という二分法を外す根拠として使用。
   - https://doi.org/10.1146/annurev-psych-010814-015331

4. Mind Wandering and Task Performance
   - Randall et al. (2014)のmeta-analysisでは、mind wanderingは概してtask performance低下と関連する。
   - 分散の利点だけを強調せず、必要な場面での集中には実際の機能的価値があることを確認。
   - https://pubmed.ncbi.nlm.nih.gov/25089941/

5. Intentionality × Meta-awareness
   - Seli et al. (2017)。mind wanderingがintentionalかどうかと、その状態に気づいているかは別次元。
   - 本稿の中心命題「分散か集中かより、自分でモードを選べているか」に直結。
   - https://pmc.ncbi.nlm.nih.gov/articles/PMC5572547/

6. Meta-awareness and Attention Control
   - Christian et al. (2026)。automaticなinternal/external attentionからcontrolled attentionへ移るときの共通ネットワークを報告。
   - 「内面へ向く＝失敗、外界へ向く＝集中」という単純化を避け、現在地の把握と再方向づけを重視する補助線として使用。
   - https://www.nature.com/articles/s42003-026-10410-w

7. Attention Economy
   - Taylorは情報が豊富な環境で注意が希少になる構造を論じる。
   - Hindmanはdigital competitionで人を引きつけ、長く滞在させ、戻ってこさせる`stickiness`の価値を扱う。
   - https://academic.oup.com/book/35088/chapter-abstract/299134506
   - https://academic.oup.com/princeton-scholarship-online/book/18027/chapter-abstract/175888685

8. Value-modulated Attentional Capture
   - Pearson et al. (2022)。rewardと関連づけられたstimulusは、現在のgoalと一致しない場合でもattentionを引きつけうる。
   - 経済的インセンティブと認知的captureを同一視せず、「両方が接続しうる構造」として使用。
   - https://www.nature.com/articles/s44159-022-00053-z

9. Rest / Cognitive Fatigue
   - Schumann et al. (2022)。注意疲労・休息についてresource depletionだけでなく、satiation、motivation、opportunity-costなど複数の理論を整理。
   - 「分散すると脳のカロリーが減る」というbattery比喩を事実扱いしないための修正根拠。
   - https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2022.867978/full

10. Task Switching / Interruptions
   - Kiesel et al. (2010)はtask switchingにおけるcontrolとinterferenceをレビュー。
   - 切り替え自体を悪とせず、頻繁で非自発的な切り替えがcontrol demandsを生むという整理に使用。
   - https://pubmed.ncbi.nlm.nih.gov/20804238/

## 2. Structure｜Uneven Uでの構造化

### 導入

4: 集中とは何か。長時間一点を見ることなのか
→ 1: スマホを閉じた直後「何を見ていたんだっけ」となる具体感
→ 2: 時間も場所も変わっていないのに「私」だけ遠い
→ 3: durationでは集中を説明できない
→ 4: Now / Here / Meという三点へ分解
→ 5: 集中を「時間・場所・主体が同じ対象へそろう状態」と再定義

### 1. 集中は「長く続けること」ではない

4: 集中をdurationで測ることへの疑問
→ 1: 30分の無目的動画視聴 vs 5分書いて窓を見る
→ 2: attentional captureの具体的な制御要因
→ 3: 注意移動はwillpowerだけでは説明できない
→ 4: 「Me」＝移動後にも目的を保持し戻れるか
→ 5: 集中の反対は注意移動ではなく、移動に自分が参加できなくなること

### 2. 分散していることは、悪ではない

4: Now / Here / Meを常時そろえることも誤り
→ 2: mind wanderingという通常の現象
→ 1: 未来計画、帰り道の再解釈、発想遊び
→ 3: task costとcreativity/future planningの両面
→ 4: intentionalityとmeta-awarenessを分離
→ 5: 善悪の軸をfocus/diffusionからmode-selection freedomへ移す

### 3. アテンションエコノミーは「ここ」と「私」をずらす

4: 「企業が集中を奪う」という表現の精度を問う
→ 2: attention scarcity / stickiness
→ 1: recommendation、notification、reward-linked stimulus
→ 3: 経済側の「見てもらいたい理由」と認知側のcapture可能性を接続
→ 4: Hereは目前taskからずれ、Meは自分のgoalから他者のgoalへずれる
→ 5: 問題はtime theftではなく、attentionの進行方向に複数のdriverが乗り込むこと

### 4. ずっと分散していると、なぜ疲れるのか

4: 「分散するとカロリーを使う」という直感を検証
→ 2: resource modelだけではないfatigue theories
→ 1: task switchでruleを切り替え、戻す具体
→ 3: 広く考えることと非自発的switchを分ける
→ 4: Now / Here / Meをfatigue detectionに転用
→ 5: 集中は作業継続技術だけでなく、自分の疲れを発見する静止点でもある

### 5. 「今・ここ・私」は集中力テストではなく、モード判定器である

4: 三点をscore化しない
→ 1: writing / strategy / restの三場面
→ 2: 各場面でNow / Here / Meの意味が変わる
→ 3: 一つがNOでもintentionalなら問題ではない
→ 4: 危険なのはNOそのものではなく、長く気づけないこと
→ 5: focusとは現在地を把握し、必要ならdirectionを変えられること

### 6. 集中力より、「注意の主導権」を取り戻す

4: 「もっと長く集中」モデルから離れる
→ 2: attentionは未来・過去・salient stimulusへ自然に動く
→ 1: 「いま何をしている／注意はどこ／これは自分が選んだか」の三問
→ 3: returnまたはintentional driftを選べる
→ 4: focusは直線ではなく往復運動
→ 5: 守るべき希少資源をattention quantityからattentional agencyへ引き上げる

## 3. Re-research｜反証・修正

### 初期仮説1

「集中していることは良く、分散していることは悪い。」

### 反証

Mind wanderingはtask performanceを損なう場合がある一方、future planningやcreativityにも関わる。さらにintentional mind wanderingとunintentional mind wanderingは区別される。

修正：**focus / diffusionそのものではなく、場面に応じてモードを選択・変更できるかを評価軸にする。**

### 初期仮説2

「アテンションエコノミーは私の注意を奪う。」

### 反証

外部刺激は人間のagencyを必ず消すわけではない。attention controlはtop-down / bottom-up / selection historyの競合として扱う方が正確。

修正：**「奪う」より「自分の目的以外のdriverがattention directionへ参加し、誰の目的で動いたかを判別しづらくする」と表現する。**

### 初期仮説3

「分散状態は脳のカロリーを消費する。」

### 反証

Cognitive fatigueを単一の有限resourceやbatteryとして説明することには限界があり、motivationやopportunity costなど複数モデルがある。

修正：**生理的battery比喩を外し、「非自発的な切り替え・制御要求が続くこと」と主観的疲労を区別して書く。**

### 初期仮説4

「今・ここ・私が全部YESなら常に正しい。」

### 反証

未来計画、メタ思考、creative explorationでは、現在の課題から意図的に離れること自体に価値がある。

修正：**Now / Here / Meを集中力スコアではなくmode detectorとして使う。一つがNOでもintentionalなら失敗扱いしない。**

### 最終中心命題

**集中の反対は、注意が動くことではない。注意が動いたとき、その移動に自分が参加できなくなることである。必要なのは注意を固定する能力ではなく、集中・分散・休息を自分の目的に応じて選び、現在地を取り直せるattentional agencyである。**

記事末の要約命題：

**Attention is scarce, but agency over attention may be scarcer.**

## 4. Prompt｜再利用プロンプト

あなたは、集中や生産性を「長時間ひとつの作業を続ける能力」として単純化せず、注意の方向、意図性、meta-awareness、環境設計、休息まで含めて分析するリサーチャー兼エッセイ編集者です。

### Phase 1｜Research

対象テーマを次の7層に分けて調べてください。

1. Target：いまattentionは何を対象にしているか
2. Time：現在・過去・未来のどこへattentionが向いているか
3. Place / Context：現在のtask・相手・身体・環境と接続しているか
4. Intention：そのattention shiftはintentionalかunintentionalか
5. Meta-awareness：attentionの現在地に本人が気づいているか
6. External Incentive：誰がattentionを動かしたいのか、どんなbusiness / social incentiveがあるか
7. Recovery / Switching：attentionを戻す・散らす・休ませる選択肢があるか

一次資料、査読論文、systematic review、公式資料を優先してください。認知メカニズムと経済的インセンティブを混同せず、それぞれ別の証拠で支えてください。

### Phase 2｜Structure with Uneven U

各段落を、固定テンプレートではなく次の運動として設計してください。

- 高い抽象度で問いを置く
- 読者が想像できる場面・観察へ降りる
- 必要な研究・事実へさらに降りる
- 具体からパターンを抽出する
- 段落冒頭では言えなかった新しい命題へ上がる

目安は`4 → 3 → 2 → 1 → 2/3 → 4 → 5`。ただし数字の順番を守ることより、段落末が認識的に前進していることを優先してください。

文章全体でも、各段落の到達点を次の段落の出発点にしてください。最後は個別のtipsではなく、そのテーマを見るための一段上のprincipleへ到達させてください。

### Phase 3｜Re-research / Falsification

初稿の中心命題について、最低3つの反証を探してください。

特に次を疑ってください。

- focus good / diffusion badの二分法になっていないか
- `attention capture`を「自由意志の消失」と誇張していないか
- mind wanderingのbenefitだけ、またはcostだけを選んでいないか
- fatigueをbattery / calorie depletionとして断定していないか
- attention economyのbusiness incentiveとcognitive mechanismを同一視していないか
- “今ここ”をmindfulnessの既成尺度として誤認していないか

反証を受けて中心命題を書き換え、より限定的で強い主張にしてください。

### Phase 4｜Now / Here / Me Lens

実用フレームワークとして次を使ってください。

- Now：いま扱う必要がある時間にいるか
- Here：attentionの主対象は、自分が置きたい場所にあるか
- Me：その向きを、自分のgoalから選んだか

ただし三つを常時YESにすることを目的にしないでください。未来計画、creative exploration、restではintentionalにずらす場合があります。評価すべきはYESの数ではなく、本人が現在地を認識し、必要ならmodeを切り替えられるかです。

### Phase 5｜Final Quality Gate

各段落について次を確認してください。

1. 冒頭と末尾が同じ内容の言い換えになっていないか
2. 具体例を削ると成立しない新しい洞察が末尾にあるか
3. 次の段落が前段落の到達点を引き継いでいるか
4. 事実と筆者の仮説・フレームワークを区別しているか
5. 集中を道徳化せず、分散を怠慢扱いしていないか
6. 読後に「集中力を上げる」より一段深い言葉で問題を説明できるか

最終的に、読者が読む前には言えなかった一文へ到達させてください。

このテーマの場合の到達候補は、次です。

**集中とはattentionを止めることではなく、attentionの現在地を知り、その方向を自分で選び直せることである。**
