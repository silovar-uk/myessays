## 1. Research｜一次調査

### 出発点

前稿では「集中していないこと自体は悪ではない」とした。しかし、それだけでは弱い。では、集中していない時間には何が起きているのか。さらに、電車待ち、エレベーター、信号、休憩などの小さな空白を、ほぼ反射的にスマートフォンで埋めるようになったとき、私たちは何を失い、何を得ているのか。

本稿では「ぼんやり」を美化しない。`mind wandering`、`prospection`、`default mode network`、`creative incubation`、`spontaneous smartphone checking`、microbreak研究を接続し、「空白を持つ権利」を`attentional agency`の一部として考える。

### 接続した理論・資料

1. Seli et al. (2017) / Intentionality × Meta-awareness
   - mind wanderingがintentionalかどうかと、その状態にmeta-awareかどうかは別dimension。
   - 「ぼんやり＝無意識」「ぼんやり＝休息」と一括りにしない基礎。
   - https://pmc.ncbi.nlm.nih.gov/articles/PMC5572547/

2. Chu et al. (2023) / Meta-awareness Systematic Review
   - self-caught mind wanderingを扱った39 studiesをreview。mind wanderingの測定法には大きなheterogeneityがある。
   - 「ぼんやりの量」を単一の客観値のように扱わないための確認。
   - https://doi.org/10.1016/j.concog.2022.103463

3. Kvavilashvili & Rummel (2020) / Everyday Prospection
   - everyday future thoughtのreviewでは、人が自然に未来を考えるとき、奇抜なhypothetical scenarioより、upcoming tasksやplansについて考えることが多い。
   - prospective thoughtsはしばしばspontaneousで、計画実行と関連する可能性が整理されている。
   - https://doi.org/10.1177/1089268020918843

4. Menon (2023) / 20 Years of Default Mode Network
   - DMNを単なる「休んでいる脳」のnetworkではなく、self-reference、social cognition、episodic memory、language、semantic memory、mind wandering等を統合しinternal narrativeを支えるnetworkとして整理。
   - `default = idle`という誤読を避ける。
   - https://pmc.ncbi.nlm.nih.gov/articles/PMC10524518/

5. Yeshurun, Nguyen & Hasson (2021) / Sense-making
   - DMNをintrinsic processだけでなく、external inputとprior knowledgeを統合してcontext-dependent modelを作るactive sense-making networkとして捉えるPerspective。
   - 「外部集中 vs 内部ぼんやり」という二分法を弱めるために使用。
   - https://www.nature.com/articles/s41583-020-00420-w

6. 2026 Review / Spontaneous Thought × Memory Consolidation
   - spontaneous thoughtとneural reactivationの関係をreviewし、memory stabilization、abstraction、generalizationとの接続を論じる。
   - reviewであり、「ぼんやりすれば記憶が必ず良くなる」という因果主張には使わない。
   - https://doi.org/10.1016/j.cobeha.2025.101622

7. Baird et al. (2012) / Creative Incubation
   - undemanding task中のincubationで、以前に取り組んだcreative problemsのperformance改善を報告。
   - 「退屈な活動中のmind wanderingが創造性を助ける可能性」の古典的根拠。
   - https://pubmed.ncbi.nlm.nih.gov/22941876/

8. Teng et al. (2022) / Mind Wandering and Incubation
   - mind wanderingのquantityだけでなくdiversity等のqualityがincubationに重要かを検討。既存研究がmixedであることも整理。
   - 「ぼんやり＝創造性UP」という神話化を止めるための反証。
   - https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0267187

9. Berntsen et al. (2023) / Digital Daydreaming
   - notificationがなくても反射的にphoneを確認する`spontaneous smartphone checking`を尺度化。
   - internally generated spontaneous thoughtとは異なるmental / social functionを持ち、長期的には内部生成思考の時間を占めうる可能性を論じる。
   - https://doi.org/10.1002/acp.4034

10. Dora et al. (2021) / Fatigue, Boredom and Smartphone Use at Work
   - n=83のPhD candidatesを対象に、疲労・退屈が高いほどsmartphoneへ手を伸ばしやすい一方、smartphone use後にfatigue / boredomが高い関連も観察。
   - causal conclusionは不可。phone break = recoveryと決めつけない材料。
   - https://doi.org/10.1098/rsos.201915

11. Grobelny et al. (2024) / Social Media Microbreaks
   - preregistered experiment, n=308 employees。algorithmic videoを使うsocial media microbreakは一定のresource recoveryを示すが、fatigueではfull recoveryに至らず、nature exposureの方がbeneficialだった。
   - smartphone/social mediaを全面否定せず、break typeによる違いとして扱う。
   - https://www.nature.com/articles/s41598-024-72825-x

12. Yildirim & Rummel (2026) / Smartphone vs Quiet Break
   - within-subject designで2-back task間のsmartphone breakとquiet breakを比較。
   - subsequent task performance、mind wandering frequencyにsignificant differenceなし。smartphone break後はpositive moodが高かった。
   - 「スマホが空白を破壊し、認知を必ず悪化させる」という強い主張への重要な反証。
   - https://pubmed.ncbi.nlm.nih.gov/41762666/

## 2. Structure｜Uneven Uでの構造化

### 導入

4: 何もしない時間は、本当に何もしていないのか
→ 1: elevator 30秒、信号待ち、電車待ちでphoneを開く
→ 2: blank timeがexternal inputへ変わる
→ 3: 空白の消滅ではなく、attention sourceの切り替え
→ 4: internally generated thoughtへ問いを移す
→ 5: attention economyの対象はfocusだけでなく、未使用に見える空白時間でもある

### 1. 「ぼんやり」は一つの状態ではない

4: mind wanderingの雑な一括り
→ 2: intentionality / meta-awarenessの二軸
→ 1: deliberate walk, unnoticed drift, aware-but-unplanned thought
→ 3: 同じoff-taskでもagencyが違う
→ 5: blank timeの価値は「集中していないこと」ではなく、attention sourceを選べる余白にある

### 2. 心は勝手に未来へ行く

4: `Now`から離れることはlossなのか
→ 1: everyday prospectionでupcoming tasks / plansが多い
→ 2: future thoughtがspontaneousに起こる
→ 3: wanderingはgoal managementの一部になりうる
→ 4: “not now”が未来のNowを準備する
→ 5: 現在から離れることが、現在を捨てることとは限らない

### 3. Default Modeは「何もしていない脳」ではない

4: rest = offというcomputer metaphor
→ 1: DMN research
→ 2: self-reference / memory / language / social cognition / internal narrative
→ 3: external inputとprior knowledgeのintegration
→ 4: spontaneous thoughtとmemory reactivation研究
→ 5: blank timeをzero activityではなくinternal model maintenanceの可能性として見る

### 4. ぼんやりすればアイデアが出る、は半分だけ本当

4: creativity romanticism
→ 1: Baird 2012 incubation effect
→ 2: later mixed evidence / quality and diversity
→ 3: mind wandering quantityを増やせば良いわけではない
→ 4: creative valueはtask timing / content / modeに依存
→ 5: 空白はidea factoryではなく、探索を許すroomである

### 5. スマホは空白を壊すのか

4: digital detox的断定を疑う
→ 1: spontaneous checking / work-study / 2024 microbreak / 2026 smartphone-vs-quiet
→ 2: negative, mixed, positive findingsが共存
→ 3: phone = poisonではない
→ 4: それでもinternally generated thoughtとはsourceが異なる
→ 5: 問題はsmartphone useではなく、「空白になった瞬間のdefaultを誰が決めるか」

### 6. 「何もしない」を自分で選ぶ

4: attentional agencyへ戻る
→ 1: recovery / incubation / inputの3種類のbreak
→ 2: 目的によってsmartphone / walk / silence / musicを選ぶ
→ 3: no-inputを万能化しない
→ 4: `Now・Here・Me`でMeだけは残す
→ 5: **Unclaimed attention is not wasted attention.**

## 3. Re-research｜反証・修正

### 初期仮説1

「mind wanderingは創造性に良い。」

### 反証

incubationを支持する研究はあるが、結果はmixedであり、mind wanderingの量より内容・diversity・timingが重要な可能性もある。

修正：**ぼんやりをcreativity hackにせず、探索可能性を残すmodeとして扱う。**

### 初期仮説2

「DMNは脳が休んでいるときのnetworkである。」

### 反証

近年のreviewはDMNをself-reference、memory、semantic processing、internal narrative、sense-making等に関わるactive networkとして整理する。

修正：**`default`を`idle`と訳さず、internally oriented / integrative cognitionの一部として説明する。**

### 初期仮説3

「スマホ休憩は休息にならない。」

### 反証

2024 studyではsocial media microbreakに部分的recovery、2026 studyではquiet breakと比べてsubsequent performance / mind wanderingに差がなく、moodはsmartphone条件で改善した。

修正：**phone vs no-phoneの善悪から離れ、breakの目的とattention sourceの選択へ移す。**

### 初期仮説4

「スマホがmind wanderingを奪っている。」

### 反証

spontaneous smartphone checkingがinternally generated thoughtの時間を占める可能性は議論されているが、長期因果が確立しているとは言えない。2026 break studyではbreak中のmind wandering frequencyにもsignificant differenceがなかった。

修正：**「奪う」と断定せず、空白スロットでinternal / external attentionが競合する設計上の問いとして提示する。**

### 最終中心命題

**集中を自分で選べることが自由なら、集中しない時間を自分で残せることも自由である。空白は生産性のために常に最適化すべき資源ではない。未来を考え、記憶をつなぎ、何も決めずに探索するための、まだ誰の目的にも予約されていないattentionである。**

記事末の要約命題：

**Unclaimed attention is not wasted attention.**

## 4. Prompt｜再利用プロンプト

あなたは、休憩・退屈・mind wandering・smartphone useを単純な善悪で語らず、「attention sourceを誰が選んでいるか」というagencyの観点から分析するリサーチャー兼エッセイ編集者です。

### Phase 1｜Research

空白時間を次の7層に分けて調べてください。

1. Task relation：on-task / task-unrelated / task-related internal thought
2. Intentionality：deliberate / spontaneous
3. Meta-awareness：本人がattention stateに気づいているか
4. Temporal direction：past / present / future
5. Source：internally generated / externally supplied
6. Function：recovery / prospection / memory / creativity / mood regulation / avoidance
7. Agency：そのmodeを本人が選択・変更できるか

### Phase 2｜Structure

Eric HayotのUneven Uを用い、具体的な数十秒の空白から始め、mind wandering → prospection → DMN → smartphone → attentional agencyへ抽象度を上げる。

段落末は「スマホをやめよう」ではなく、「空白のdefaultを誰が決めるか」という一段大きい問いへ進める。

### Phase 3｜Re-research

必ず次を反証する。

- mind wanderingはcreativityを高めるのか
- DMNはrest networkなのか
- smartphone breakは回復を妨げるのか
- phone checkingがinternal spontaneous thoughtを減らす因果は確立しているか

### Phase 4｜Practical Translation

breakを次の3種類に分類して選ぶ。

- Recovery：疲労を下げたい
- Incubation：問題から一度離れたい
- Input：刺激や情報が欲しい

no-inputを正解にしない。目的に合っているかを判定する。

### Quality Gate

- digital detox説教になっていない
- mind wanderingを創造性hackとして神話化していない
- DMNの機能を単純化しすぎていない
- 2026年の反証的smartphone studyを無視していない
- 結論が「空白も自分で選ぶattentional agency」へ到達している
