# インテンションエコノミー × ファンベース 制作ノート

Date: 2026-09-15
Target essay id: `intention-economy-fanbase-relation-before-intent`

## 1. Research｜一次調査

### 最初の問い

「次に買うものを予測できるとして、その人が“それを欲しがる人”になった過程はどこへ行くのか？」

前作のインテンションエコノミーでは、意図を予測・推薦・実行する主体の問題まで進んだ。続編では意図を所与の信号と見なさず、意図が生まれる前史を扱う。

### 接続した理論・概念

1. ファンベース
   - ファンとの「長く続くいい関係性」を基盤に、中長期的に売上や価値を高める考え方。
   - ファンマーケティングとの差として、ファンをターゲットではなく支持母体、仲間・パートナーとして捉える。
   - https://www.fanbasecompany.com/about/
   - https://www.fanbasecompany.com/faq/

2. Commitment-Trust Theory of Relationship Marketing
   - Morgan & Hunt (1994)。成功するrelationship marketingにrelationship commitmentとtrustが重要なmediatorになるという理論・実証モデル。
   - https://doi.org/10.1177/002224299405800302

3. Brand Community
   - Muniz & O’Guinn (2001)。shared consciousness、rituals and traditions、moral responsibilityという共同体の特徴をブランド周辺でも確認。
   - 意図を個人内部だけでなく、社会関係と反復儀礼の中で形成されるものとして考える橋になる。
   - https://doi.org/10.1086/319618

4. Extended Self / Consumer-Brand Relationship
   - Belk (1988)：所有物はidentityの構成・反映に関わる。
   - Fournier (1998)：消費者とブランドの関係を生活経験の中で意味を持つ関係として検討。
   - https://doi.org/10.1086/209154
   - https://doi.org/10.1086/209515

5. Customer Engagement Behavior
   - van Doorn et al. (2010)。purchaseを超えるWOM、recommendation、helping、review等を顧客行動として扱う。
   - 「意図＝購買」だけではファンの価値を狭く捉えることを示す。
   - https://doi.org/10.1177/1094670510375599

6. Service-Dominant Logic
   - Vargo & Lusch (2004)以降の議論。goods/transaction中心からservice、relationships、value co-creationへ視点を移す。
   - https://doi.org/10.1509/jmkg.68.1.1.24036

### 水平思考で追加した接続

- stock / flowの比喩：意図は速く変化するflow、信頼・記憶・愛着はslow stockとして扱う。数理モデルとして断定せず、時間尺度を理解する比喩としてのみ使用。
- identity：意図予測を「何を買うか」の予測から、「どんな自分であり続けたいか」の予測へ拡張して考える。
- network：ファンは需要の受け手であるだけでなく、他者への推薦・共創を通じて需要の意味を作る側にも回る。
- ethics：関係が意図を作るなら、関係性マーケティングにも操作リスクがある。短期操作との違いを「相互性」「企業側も変わる余地」「非購買時にも関係を価値あるものとして扱うか」「離脱可能性」で考える。

## 2. Structure｜Uneven Uでの構造化

記事全体を「意図の予測」から「意図の前史」へ降り、最後に「意図インフラ」へ上げる。

### 導入

4: 次の購入意図を予測する市場
→ 2: チケット購入という具体例
→ 1: 過去の試合、隣席、帰り道、習慣
→ 4: なぜ未来の選択肢に最初からその行動が入っているのか
→ 5: 意図の材料は過去から来る

### 1. 意図は速い。関係は遅い

4: Intention EconomyとFanbaseは時間尺度が違う
→ 1/2: Fanbase公式定義
→ 3: stock / flow比喩
→ 5: 関係は購買後の維持ではなく、未来の選択確率を変える可能性がある

### 2. 継続と応援の違い

4: repeat purchaseだけでは関係を測れない
→ 1: trust / commitment研究
→ 2: 同じ再購入でも理由は複数
→ 3: 行動ログと関係の質を分離
→ 5: 予測可能性そのものを信頼が作る場合がある

### 3. ブランドコミュニティ

4: 意図は本当に個人内部にあるのか
→ 1: shared consciousness / rituals / moral responsibility
→ 2: 儀式・会話・伝承の具体
→ 3: social identityとuniquenessの両立
→ 5: 未来は個人の外側から共同制作される

### 4. Extended Self

4: なぜ一部の選択だけ重いのか
→ 1: Belk / Fournier
→ 2: ユニフォーム、贈り物等の例
→ 3: 過去の消費→自己像→次の意図という循環
→ 5: intention predictionはfuture identity predictionにもなりうる

### 5. Engagement / S-D Logic

4: ファンの価値をpurchase intentだけで測れるか
→ 1: WOM、helping、review等
→ 2: ファンベースの傾聴・共創
→ 3: value co-creationとの接続
→ 5: 市場は意図を捕まえるだけでなく、意図が生まれる土壌を育てている

### 6. 関係と操作

4: 関係が意図を作るならFanbaseもmanipulationにならないか
→ 1/2: Fanbase公式がtargetでなくpartnerを強調
→ 3: asymmetryは残る
→ 4: 「今日買わなくても関係に価値があるか」という監査問い
→ 5: intention ethicsはrelationship qualityまで含む

### 7. 意図インフラ

4: AIはslow relationshipも予測できるかもしれない
→ 2: 長期履歴もデータ化可能
→ 3: 重要なのは予測困難性ではなく生成過程
→ 5: Fanbase = intention infrastructure
→ 次作への問い: その選択自体をAIへ委任したら何が起きるか

## 3. Re-research｜再リサーチと修正

### 修正した点

NG: 「ファンは必ず高LTVである」
OK: ファンベースカンパニーは売上・LTVとの関係を実務フレームとして提示しているが、あらゆる業種・状況に普遍化しない。本稿では中心根拠にしない。

NG: 「ブランドコミュニティに入ると同じものを選ぶ」
OK: group identificationとuniquenessは両立しうる。共同体は選択を一方向に統一するのではなく、選択の意味や参照枠を作る。

NG: 「関係性はAIには予測できない」
OK: 長期履歴や会話を扱うAIなら関係の兆候も推定対象になりうる。Fanbaseの価値を“AIが読めない秘密”には置かない。

NG: 「Fanbaseは操作ではない」
OK: 実務理念としてpartner / co-creation / listeningを重視していても、企業と顧客の非対称性は残る。操作との境界は個別設計で監査する。

NG: 「S-D Logic = Fanbaseの学術的証明」
OK: 両者は別系統の概念。transaction以外の価値形成を考えるための“接続可能なレンズ”として扱う。

### 最終的に残した中心命題

**購入意図は、孤立した未来信号ではなく、信頼・共同体・記憶・自己像・共創の履歴から生成される。Fanbaseはその意味で、retentionではなくintention infrastructureとして読み替えられる。**

## 4. Prompt｜再現用プロンプト

あなたは、既存理論同士を水平に接続し、それぞれを並べて紹介するのではなく、接続によって元の概念の意味を変えるリサーチャー兼エッセイ編集者です。

テーマAとテーマBを与えられたら、次の順で制作してください。

### Phase 1｜Research

1. テーマA、Bそれぞれの公式定義・原典・代表研究を確認する。
2. 同義語探しではなく、両者が見ている「時間尺度」「主体」「価値単位」「因果方向」「観測単位」の違いを探す。
3. さらに第三、第四の理論を横から接続する。候補はrelationship、identity、community、behavioral economics、systems thinking、service research、network、ethicsなど。
4. 実務フレームと学術理論を同格の“証明”として扱わず、由来と根拠の種類を明記する。

### Phase 2｜Structure with Uneven U

各段落を、問題設定→具体→原典・事実→再解釈→一段上の洞察へ動かす。

典型形は4→3→2→1→2/3→4→5。ただし順番より、「具体を通った後にしか言えないこと」へ進むことを優先する。

段落の終点を次段落の出発点にする。

### Phase 3｜Horizontal expansion

MECEを目指さない。

代わりに、次の“変形が起きる接続”を優先する。

- 未来を見る理論 × 過去を蓄積する理論
- 個人の理論 × 共同体の理論
- 取引の理論 × identityの理論
- 効率の理論 × ethicsの理論
- 短期のsignal × 長期のstate

接続しても結論が変わらない理論は削る。

### Phase 4｜Re-research

初稿に都合の悪い反例を探す。

- 理論の適用範囲を越えていないか
- 相関を因果にしていないか
- practitioner claimを普遍法則にしていないか
- AIにできないと根拠なく決めていないか
- “関係”“共創”“ファン”という好意的な言葉でpower asymmetryを隠していないか

反例は削除せず、論旨を一段深くする材料にする。

### Phase 5｜Draft

最後はA+Bの要約で終わらない。

AとBを接続した結果、新しい名前を付けられるほどの概念的到達点を作る。ただし、新語は既存学術用語のように扱わず「本稿ではこう呼ぶ」と明示する。

完成後、各段落について「読む前には言えず、読んだ後なら言えること」を1文で監査する。
