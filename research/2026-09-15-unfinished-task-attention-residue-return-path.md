## 1. Research｜一次調査

### 出発点

前稿では、集中を「注意を固定する能力」ではなく、集中・分散・休息を自分の目的に応じて切り替えられる`attentional agency`として捉えた。

ただし、ここにはまだ抜けがある。人は「次のタスクへ移る」と決めた瞬間に、認知的にも完全に移動できるとは限らない。ブラウザのタブは閉じられても、未完了の仕事は頭の中で開いたままになりうる。

そこで本稿では、集中の問題を「どれだけ長く居続けられるか」から「どう離れるか」へ移す。中心概念は`attention residue`、`interruption / resumption`、`ready-to-resume plan`である。

### 接続した理論・資料

1. Sophie Leroy (2009) / Attention Residue
   - 複数の仕事を切り替えるとき、とくに未完了のタスクから離れた場合、前タスクへの注意が残り、次タスクのperformanceが低下しうることを二つの実験で示した。
   - 「タブを閉じればtaskも終わる」という素朴なtransition観を崩す根拠。
   - https://doi.org/10.1016/j.obhdp.2009.04.002

2. Leroy & Glomb (2018) / Ready-to-Resume Plan
   - interruption後に元のtaskへ戻る時間的圧力を予期するとattention residueが生じ、割り込んできたtask側のperformanceにも悪影響が出る。
   - 中断前に「どこまで進んだか／どこから再開するか」を短く考えるready-to-resume planが、その影響を緩和した。
   - 4 studiesの結果。万能な治療法ではなく、特定条件でのinterventionとして扱う。
   - https://doi.org/10.1287/orsc.2017.1184

3. Mark, Gudith & Klocke (2008) / Interruptions
   - interruptionを受けた参加者は必ずしも作業完了が遅くなるわけではなく、より速く処理して補償する場合があった一方、stress、frustration、time pressure、effortが増加した。
   - interruption costを「時間ロス」だけで測らないために使用。
   - https://doi.org/10.1145/1357054.1357072

4. Trafton et al. (2003) / Preparing to Resume
   - interruption前に予告時間があると、参加者は復帰のための準備を行い、primary taskへのresumptionが速くなった。
   - 「戻り道を先に作る」という考えに、attention residueとは別系統のmemory-for-goals研究から補助線を引く。
   - https://doi.org/10.1016/S1071-5819(03)00023-5

5. Hirsch et al. (2024) / Resumption Costs
   - interruption contextにおけるresumption costの認知過程について、suspended task goalのdecayかinhibitionかを検討。
   - resumption costという現象があっても、その内部機構を単一説明へ固定しないために使用。
   - https://doi.org/10.3758/s13421-023-01458-8

6. Moosavi et al. (2024) / Critical Review of Interruptions and Workload
   - 33 papersを対象に、interruptionsとcognitive demandをworking memory、stress、emotional state、performance、resumption lagなどの観点から整理。
   - interruption研究の測定・条件が多様で、単一の「中断コスト」へ圧縮しないための確認。
   - https://sam.ensam.eu/handle/10985/25123

## 2. Structure｜Uneven Uでの構造化

### 導入

4: task switchは、画面を切り替えた瞬間に完了するのか
→ 1: 文章途中でSlack対応、戻って数十秒「どこまで考えていた？」
→ 2: UI上は切り替わったがmental stateは切り替わっていない
→ 3: transitionにはvisible stateとinvisible stateがある
→ 4: attention residueへ接続
→ 5: 集中力の問題を「居続ける能力」から「きれいに離れる能力」へ拡張

### 1. タブを閉じても、頭のタブは閉じない

4: unfinished taskの切り替え
→ 1: Leroy 2009のtask switching experiments
→ 2: 前のtaskへのattentionが次へ残る
→ 3: switch costを操作時間ではなくmental carryoverとして理解
→ 5: task boundaryはクリックではなく、attentionが移動し切った場所にある

### 2. 中断のコストは「遅くなる」とは限らない

4: interruption = productivity lossという単純化
→ 1: Mark et al. 2008で速度はむしろ上がる場合
→ 2: stress / frustration / time pressure増加
→ 3: 人はcostをperformanceで隠して補償することがある
→ 5: 忙しく回せている日は、切り替えコストがない日ではなく、自分が請求書を引き受けている日かもしれない

### 3. 「忘れないようにしておく」が、次の仕事を邪魔する

4: 未完了taskを保持する理由
→ 1: interruption後に戻る必要がある
→ 2: memory for goals / resumption lag
→ 3: mechanismにはdecay / inhibitionなど議論がある
→ 4: 問題はmemory failureだけでなく、未来の復帰を現在のattentionで担保しようとすること
→ 5: 戻り道を脳内で保持し続けるほど、現在地は狭くなる

### 4. 戻り道を紙に置く

4: mental carryoverをゼロにする方法ではなく、未来への約束を外部化する
→ 1: Leroy & Glombのready-to-resume intervention
→ 2: 「どこまで／次に何／いつ戻る」の3点へ実務化
→ 3: external representationがprospective burdenを軽くする可能性
→ 4: closing ritualをproductivity habitではなくboundary deviceとして再定義
→ 5: 良い終了とは、忘れることではなく、安心して忘れられる状態を作ること

### 5. 時間管理より、境界管理

4: calendar / timer / Pomodoroは時間の箱を作る
→ 1: 会議→企画→メール→SNS確認の現実
→ 2: box間のtransitionが空白のまま
→ 3: start ritual偏重、exit ramp不足
→ 4: boundary design = destinationだけでなくreturn pathを設計
→ 5: productivityの単位を「集中した分数」から「完全に移動できた回数」へずらす

### 6. 集中とは、うまく離れられることでもある

4: 前稿のattentional agencyへ戻る
→ 1: leave / park / resumeの三動作
→ 2: Now・Here・Meをtransitionへ適用
→ 3: Meが未来の自分へ再開地点を渡す
→ 4: attention controlは滞在だけでなくdepartureにも存在する
→ 5: **A good boundary is a promise to your future attention.**

## 3. Re-research｜反証・修正

### 初期仮説1

「task switchingは悪い。」

### 反証

仕事では複数taskの切り替えは不可避であり、研究もすべてのswitchを一律に有害とするものではない。Attention residueではunfinished taskからのtransitionが重要な条件になる。

修正：**switchそのものではなく、前taskとの認知的な接続が残ったまま次へ移るtransitionを問題にする。**

### 初期仮説2

「interruptionは仕事を遅くする。」

### 反証

Mark et al.ではinterruptionsを受けた参加者が速く作業する補償も見られた一方、stress等が増えた。

修正：**costをtime / qualityだけでなく、effort / stress / pressureにも分解する。**

### 初期仮説3

「attention residueの原因は未完了taskを忘れないためである。」

### 反証

resumption costのunderlying mechanismにはdecay / inhibitionなど複数の説明があり、単一機序として断定できない。

修正：**「未来の復帰を現在の認知が保持する」という現象レベルの説明に留め、脳内機構を断定しない。**

### 初期仮説4

「ready-to-resume planを書けば解決する。」

### 反証

2018研究は特定のinterruption / time-pressure条件での4 studiesであり、あらゆるwork contextへの万能性を示してはいない。

修正：**evidence-backedな小さなboundary interventionとして提示し、自分の仕事で試す実験にする。**

### 最終中心命題

**集中力は、同じtaskに長く居座る能力だけではない。未完了の仕事から離れるとき、未来の自分へ再開地点を渡し、現在のattentionを次の場所へ完全に移せることもattentional agencyである。**

記事末の要約命題：

**A good boundary is a promise to your future attention.**

## 4. Prompt｜再利用プロンプト

あなたは、productivityやtask switchingを「集中時間を増やす問題」に単純化せず、task boundary、attention residue、interruption、resumption、prospective burdenまで含めて分析するリサーチャー兼エッセイ編集者です。

### Phase 1｜Research

対象となる仕事の切り替えを次の7層で調査してください。

1. Exit condition：前taskはcompleted / unfinishedのどちらか
2. Trigger：switchは自発的か、interruptionか
3. Carryover：前taskのgoal / emotion / next stepがどれだけ残るか
4. Resumption demand：戻る必要があるか、いつ戻るか
5. External memory：再開地点が外部化されているか
6. Compensation：速度・努力・stressでcostを隠していないか
7. Boundary design：終了・保留・再開のritualがあるか

一次論文、review、replication / later studiesを優先する。task switching、interruption、attention residue、resumption lagを同一語として雑に扱わない。

### Phase 2｜Structure

Eric HayotのUneven Uを使い、各段落を`4→2→1→3→4→5`程度で動かす。段落末は「切り替えは大変だ」の要約ではなく、「良い終了とは何か」へ認識を進める。

文章全体では、`switch cost → unfinished goal → return path → boundary management → attentional agency`と抽象度を上げる。

### Phase 3｜Re-research

必ず次を反証する。

- task switchingは常に悪いのか
- interruptionは必ず遅延を生むのか
- attention residueのmechanismは確定しているか
- ready-to-resume planはどこまで一般化できるか

### Phase 4｜Practical Translation

研究をそのままlife hack化せず、低コストな試行として翻訳する。

推奨する3行exit ramp：

- 今どこまで進んだ？
- 次の一手は何？
- いつ／何を合図に戻る？

### Quality Gate

- 「switch＝悪」にしていない
- performance costとsubjective costを分けている
- mechanismを断定しすぎていない
- adviceが研究のevidence範囲を超えていない
- 結論が前稿のattentional agencyを更新している
