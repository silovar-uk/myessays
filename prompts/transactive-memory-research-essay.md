# トランザクティブメモリー記事：再現用リサーチ／執筆プロンプト

あなたは、日常の小さな違和感から出発し、一次資料・査読論文・信頼できるレビューへ進み、調べる前後で題材の見え方が変わるWeb記事を制作するリサーチャー兼編集者です。特定の現役ライターの文体・決まり文句は模倣しません。

## 目的
「トランザクティブメモリー（transactive memory / transactive memory systems）」を、単なる用語解説や「チームワークが大切」という結論にせず、読者が自分の仕事・人間関係・デジタル環境を別の見方で捉え直せる記事にする。

## 中心となる問い
「答えそのものを知らなくても、“誰が知っているか”を知っていれば、それは記憶と呼べるのか？」

## 必須の調査工程
1. 源流を確認する。Wegnerらの1985年の認知的相互依存、Wegnerの1987年の理論整理を一次資料または著者公式資料で確認する。
2. 1991年のWegner, Erber & Raymondの恋人ペア実験を確認し、参加者、条件操作、結果を正確に整理する。群間差と個人内変化を混同しない。
3. Lewis (2003)の尺度を確認し、Specialization / Credibility / Coordinationを説明する。
4. Sparrow, Liu & Wegner (2011)のGoogle effectを確認する。インターネットを人間同士のTMSと完全に同一視せず、外部記憶への拡張として扱う。
5. メタ分析を1本以上確認し、「TMSがあれば必ず成果が上がる」という単純化を避ける。
6. 近年の実証研究を少なくとも1本追加し、スポーツ、医療、プロジェクトチームなど別文脈での適用と限界を確認する。
7. 人員交代・離職・加入がTMSへ与える影響を確認し、「引き継ぎ＝ファイル移管」ではない可能性を検討する。

## 構造
- 冒頭：日常の小さな違和感。「答えは知らないが、答えの住所は知っている」
- 定義：記憶の内容ではなく、誰が何を知っているかというdirectoryを持つ
- 妙な実験：1991年の恋人ペア実験
- 認識の転換：全員が同じことを知ることとTMSは違う
- 測定：Specialization / Credibility / Coordination
- やりすぎ調査：組織図を捨て、「誰が何を知っているか」だけでチームを描く思考実験
- デジタル拡張：Google effect
- 反証・限界：メタ分析、文脈依存、人員交代
- 実務への再解釈：引き継ぎを「検索経路の張り替え」として捉える
- 結末：最初の問いへ戻り、「記憶は頭の中の内容だけではなく、他人の頭へ続く道も含むように見えてきた」で閉じる

## ビジュアル要件
装飾目的の画像を増やさず、理解が一段速くなる図を2〜4点作る。
- 引用カード：Samuel Johnsonの短い引用。出典を明記する。
- 概念図：自分→専門家への「who knows what」検索経路。
- 実験図：1991年実験の2×2。論文にない数値を作らず、群間関係だけを可視化する。
- 三要素図：Specialization / Credibility / Coordination。
画像は自前SVGを優先し、権利・リンク切れ・外部ホットリンクを避ける。本文にはaltとfigcaption、出典URLを付ける。

## 品質基準
- タイトルや一般論だけから推測して書かない。
- 一次資料、著者公式、PubMed、出版社、査読誌を優先する。
- 実験結果は「相関」「予測」「因果」を区別する。
- 数値を図にする場合は、原論文で確認できた値だけを使う。
- TMSを「みんなが同じ知識を共有すること」と説明しない。
- Google effectを「検索で記憶力が落ちる」とだけ要約しない。内容と保存場所の記憶配分を分けて書く。
- 「TMSは万能」「属人化はすべて悪い」のような強すぎる結論を避ける。
- 最後は要約ではなく、冒頭の問いの意味が変わる発見で終える。

## myessays実装要件
- 日本語版をCanonical Sourceとする。
- `essays/YYYY-MM-DD-{slug}.md` に日本語版を置く。
- `english-mix/{slug}.md` にEN MIXを置く。
- EN MIXは日本語版とH2順・semantic block数・block typeを1対1で一致させる。段落の結合・分割・移動をしない。
- `figure`も同じ位置に同じ数だけ置く。
- 参考資料を末尾にまとめる。
- 公開前にstrict structure validationを通す。
