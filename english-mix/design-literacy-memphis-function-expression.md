# 棚なのに、棚以上のことを言いたがる――Memphisと「機能だけでは足りない」デザイン
## Design Literacy #32｜Functionalismの外側に、meaning・emotion・cultureを足す

棚という家具は、pretty much solvedに見える。

板があって、物を置ける。

That should be enough.

ところが1981年、Ettore Sottsassがdesignした《Carlton》を見ると、棚が急に余計なことを始める。

Slanted shelves. Loud colours. Cheap plastic laminate. 中央には引き出し。全体はrobotにも、totemにも、両手を広げた人にも見える。

棚なのに、棚であることに専念していない。

**Why would anyone deliberately do this?**

「使いやすさ」がdesignの正義なら、これはかなり怪しい。

今回はそこを本気で調べる。

---

## 1. まずCarltonを『変な棚』として見る

The Metropolitan Museum of Artは《Carlton》を1981年のMemphisを代表する作品として所蔵している。

面白いのは、it looks chaotic, but it is not structurally carelessということだ。

Metの解説では、表面のvivid coloursやランダムに見えるsolid / voidの組み合わせの下に、real and implied equilateral trianglesによる論理的な構造があるとされる。さらに、slanted shelvingも単なる嫌がらせではなく、本が倒れやすい垂直棚に対してfunctionを持つ。

ここで最初の理解が少し崩れる。

**Weird form does not automatically mean anti-function.**

むしろ、functionの上に別の仕事を載せている。

### FACT

- 《Carlton》はEttore Sottsassが1981年にdesignし、Memphis Milanoが製造したroom divider / bookcase / chest of drawersの複合家具。
- MDFと比較的安価なplastic laminateを使いながら、高級市場向けに手仕事で作られた。
- 派手なsurfaceの下に、equilateral trianglesを基礎としたlogical structureがある。

### INTERPRETATION

《Carlton》の面白さは「わざと使いにくい家具」ではなく、**a useful object can also carry meaning**と露骨に示したことにある。

---

## 2. Memphisは、どこから出てきたのか

Memphisだけ見ると、1980年代に突然everything became zigzagに見える。

でも、その前段がある。

The Metは、1960〜70年代のイタリアでArchizoom、Superstudio、Studio AlchimiaなどのRadical Design / Anti-Designが、International Styleのpure functionalismへの反発として展開したと整理している。

SottsassもStudio Alchimiaに短く参加し、1979年には《The Structures Tremble》を制作した。Metはこれを、modernismのfunctionalismへ反発したAlchimiaの思想を示す例としている。

そして1981年、Memphisが始まる。

名前の由来まで妙だ。

Sottsass宅で集まっていたとき、Bob Dylanの「Stuck Inside of Mobile with the Memphis Blues Again」が流れていた。Metによれば、Memphisという言葉がAmerican city、blues、suburbia、古代エジプトの首都まで複数の意味を同時に呼び起こすことが、名前として気に入られた。

The name itself refuses to mean only one thing.

---

## 3. 『機能を否定した』ではなく、『機能だけでは足りない』

ここを雑にするとMemphisがただのteenage rebellionになる。

Sottsass自身はキャリア初期にrational / functional industrial designを手がけていた。The Metは、彼が1960年代以降、functionを超えてsymbolism、emotional appeal、global and historical referencesを持つobjectsへ関心を広げたと説明する。

つまり、

```text
FUNCTION
↓
reject
↓
DECORATION
```

ではない。

Better model is:

```text
FUNCTION
+
SYMBOL
+
EMOTION
+
HISTORY
+
CULTURE
```

Peter Shireの1981年《Two Tone Cone》についても、MetはMemphisのgoalを、functional objectsにhistoric / symbolic meaningとemotional appealを持たせることとして説明している。

**Function answers “Can I use it?” Expression answers “What does it mean?”**

機能は「使えるか」に答える。

Expressionは「これは自分にとって何なのか」に答える。

---

## 4. やりすぎ調査：Carltonからfunctionだけを残したらどうなるか

Let’s mentally strip Carlton down.

残すのは、

- 本を置ける
- 空間を仕切れる
- 引き出しがある

だけ。

Remove the colour.

Remove the pattern.

Remove the diagonals.

Remove the symbolic silhouette.

Remove the historical references.

すると、たぶんquite normal storage furnitureになる。

It works.

では逆に、functionを全部消してcolour・pattern・shapeだけ残す。

今度はfurnitureよりsculptureへ近づく。

この極端な比較で見えるのは、Memphisがその間を広げたことだ。

```text
UTILITY ───────────── EXPRESSION
        Memphis expands the space between
```

「役に立つ」と「意味がある」をzero-sumにしなくていい。

Both can coexist.

---

## 5. これをUIへ持ち込むと、急に危険になる

Furniture can afford to be looked at.

UI has tasks.

読む。探す。比較する。入力する。戻る。買う。

ここでMemphisをsurfaceだけ真似すると事故る。

```text
rotate the button
hide navigation somewhere surprising
make text difficult to read
invent a different rule for every interaction
```

That is not “postmodern freedom.”

ただoperabilityを削っている。

そこでUIではlayersを分ける。

```text
STRUCTURE
information hierarchy / navigation / interaction

↓ keep this stable first

EXPRESSION
colour / typography / photography / shape / texture / motion / microcopy
```

**Do not break the information structure first. Break the expressive layer first.**

情報構造ではなく、まずexpressionから変える。

---

## 6. Before → After：全部きれいにしたら、全部同じになった

イベントページを考える。

### Before

```text
EVENT 01
9.19 SAT
SPECIAL MATCH
[ 詳細を見る ]

EVENT 02
12.13 SUN
SPECIAL MATCH
[ 詳細を見る ]
```

Readable. Predictable. Safe.

でも、全部同じ顔をしている。

そこでstructureは変えず、expressive layerだけ変える。

### After

```text
SHARED STRUCTURE
DATE
TITLE
DESCRIPTION
CTA

EVENT A
Typography → tension

EVENT B
Illustration → celebration

EVENT C
Colour / Texture → seasonality
```

ここで欲しいのはrandomnessではない。

**Same grammar, different voice.**

これはDesign Systemとも対立しない。

むしろstructureをsystem化するほど、where expression is allowedが明確になる。

---

## 7. そのまま使える制作・修正指示

> **情報階層と主要な操作方法は維持したまま、企画固有の感情・文化・ブランド性が伝わるexpressive layerを追加してください。差別化のためにNavigationやinteraction rulesを崩すのではなく、colour・typography・photography・shape・pattern・motionなど、理解を妨げない層から変化を作ってください。**

Short version:

> **Don’t break the function. Add meaning.**

レビューでは一問。

**「この装飾は、what exactly is it communicating?」**

「なんとなく賑やかに」しか答えが出ないなら、まだsurfaceで止まっている。

---

## 8. 誤解しやすい点：Memphis＝三角・水玉・パステルではない

検索すると、Memphisっぽいgeometry、bright palette、zigzags、dotsが大量に出てくる。

Sure, those are part of the visual vocabulary.

でも、それだけ真似すると思想が抜ける。

Met所蔵のGeorge Sowden《Penrose Fruit Bowl》は、ancient pyramidにもrobotic deviceにもsunにも見えると解説される。Peter Shire《Two Tone Cone》にはBauhausやWiener Werkstätteへのreferenceが見られる。SottsassのvasesにはGreek / Roman glassやancient ceramicsへの関心も現れる。

Memphisは、**high / low, ancient / contemporary, industrial material / craft, utility / symbol**を一つのobjectに共存させた。

### FACT

Memphisではbright colours、patterns、plastic laminateなどが広く使われた。

### INTERPRETATION

だから現代制作で受け取るべきなのは“Memphis pattern”より、**the willingness to let conflicting values coexist**なのかもしれない。

---

## 9. Tschicholdと並べると、逆方向に見えて同じ問いになる

Design Literacy #29ではJan Tschicholdを扱った。

そこでは、

```text
RULE
WHY
CONDITION
EXCEPTION
```

としてruleの適用条件を考えた。

Memphisはone step earlierへ行く。

```text
Tschichold
Which rule fits this problem?

Memphis
Is this problem definition large enough?
```

「使いやすくする」だけをproblemにすると、expressionは余計に見える。

でも、人は物を使うだけでなく、意味を読み、好き嫌いを持ち、memoryやcultureと結び付けるところまで含めると、expressionは仕事になる。

これが今回のresolution upgrade。

**Before questioning the rule, question the problem the rule is trying to solve.**

---

## 10. 30秒でできる観察：なくしても使えるのに、なくすと困るもの

好きなWeb siteやappを見る。

Find one thing that can disappear without breaking the task, but whose removal would weaken identity.

例えば、

- photography tone
- typeface
- corner radius
- icon style
- illustration
- motion
- microcopy

そして聞く。

```text
Can I still use it without this?
YES

Would meaning / personality / expectation weaken?
YES
```

なら、それはexpressive layerかもしれない。

次に、そのexpressionが何を伝えているか一文で説明する。

If you cannot explain it, it may still be only decoration.

---

## 最後に：棚がこちらを見ている

最初、《Carlton》はjust a weird shelfに見えた。

派手で、斜めで、ずいぶん余計なことをしている。

でも調べた後では少し違う。

内部にはlogical structureがあり、slanted shelvesにもfunctionがあり、その上でcheap / luxury、ancient / contemporary、utility / symbolを同時に載せている。

だから《Carlton》はfunctionを馬鹿にしている家具ではない。

むしろこちらへ、ずっと聞いている。

**“It works. Is that the end of the story?”**

UIも同じだ。

迷わず操作できることはthe baseline。

そのうえで全部を正しく整えた最後に残る。

**「で、これは誰のdesignなん？」**

そこからexpressionの仕事が始まる。

---

## 今日の中心命題

**Function tells us how to use something. Expression tells us why it feels like this thing.**

機能は「どう使うか」をつくる。

Expressionは「なぜ、これなのか」をつくる。
