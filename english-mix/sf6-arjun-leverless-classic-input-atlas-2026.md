# アルジュンのレバーレス入力大全
### Press, release, hold――入力を指の状態で理解する

*調査・改稿：2026年10月24日。『ストリートファイター6』クラシック操作のアルジュン、1P側を主に解説。左右同時押し＝方向なし、上下同時押し＝方向なし（真ニュートラル方式）を前提とする。メーカーが報告した代替入力と、本記事独自の運指提案・未実測案は区別した。*

![『ストリートファイター6』アルジュンの公式キービジュアル](https://prcdn.freetls.fastly.net/release_image/13450/6108/13450-6108-6848b12f28723ab664fe46bcd7bf5c37-1920x1080.png?auto=webp&bg-color=fff&fit=bounds&format=jpeg&height=1350&quality=85%2C65&width=1950)

*冒頭写真：株式会社カプコン、[2026年10月13日のアルジュン参戦発表](https://prtimes.jp/main/html/rd/p/000006108.000013450.html)より。キャラクター画像の権利は権利者に帰属。以下の方向ボタン図は筆者作成の新規図解。*

The hardest part of leverless inputs is not remembering numbers. It's knowing **what stays pressed, what you add, and what you release**. 236と214は鏡写しに見える。しかし1Pでは236に人差し指、214に薬指が主に使われる。323も同じ。薬指で左を弾く方法ばかりに注目しがちだが、**you can make 323 without using the ring finger**.

This is a guide to input states, not a speedrun of command names. ゲームが読む方向・実際のキー・使う指・失敗時の診断をセットで解説する。[Capcom's launch release](https://prtimes.jp/main/html/rd/p/000006108.000013450.html) / [Dengeki's Classic move list](https://dengekionline.com/article/202610/89267)

## まず結論｜実戦で最初に使う入力はこれ

- **Crouching shoulder / しゃがみ肩**：323＋P。1PではDownを保持し、Rightをrelease→repress。薬指を使わない。
- **Walking shoulder / 前歩きから肩**：636＋P。右を押し続け、下を一度足して離す。
- **Pressure & projectile / 張り手と飛び道具**：236＋P「大義の巨腕」、236＋K「息吹の円筒」。Same left-hand motion, different ending button.
- **Rock setup / 岩設置**：214＋K「神気の巨巌」。下→左下→左。1Pでは薬指が主役。
- **Command grab / コマンド投げ**：63214＋P「鬼気迫る尋問」。Release Right before releasing Down.
- **Counter / 当身**：22＋強K「不撓の警衛」。下→離す→下。保持中にPで「倫理の崩壊」。
- **Super Arts**：SA1＝236236＋K、SA2＝214214＋P、SA3＝236236＋P。
- **Systems / 共通**：66／44で前後ステップ、中P＋中Kでパリィ、強P＋強Kでインパクト。

最初は使う場面を一つ決め、そこに必要な動作だけを練習する。**Don't memorize seven inputs all at once.**

## 守｜「ゲームが読む方向」と「指が押すボタン」は違う

数字はテンキーの配置を意味する。右向きの1P側では、6＝→（前）、4＝←（後ろ）、2＝↓、3＝↘、1＝↙、5＝どの方向も押していない状態。例えば「236」は下→右下→右、「63214」は右→右下→下→左下→左。数字はフレーム数ではない。

一般的な3方向ボタン＋ジャンプボタンの配置では、**薬指＝左、中指＝下、人差し指＝右、親指＝上**が一つの基本形。ただし、実際の割り当てやボタン間隔によって最適な指は変わる。左右の親指の使い分けも固定しない。

ここで重要なのが、同時逆方向入力の処理（SOCD）。今回の真ニュートラル方式では、右＋左が同時に押されると水平方向が消える。つまり**右＋下＋左＝下**とゲームに伝わる。上＋下も無入力になるが、これは上優先式と異なる。[ヒットボックス・アーケード（Hit Box Arcade）の同時逆方向設定](https://www.hitboxarcade.com/blogs/hit-box/socd-modes-on-hit-box)

以降の図は「← ↓ → ↑」の順に物理ボタンを並べ、**青＝押しているボタン、右側の数字＝ゲームが受け取る方向**としている。ボタンの位置関係を正確に再現した製品写真ではなく、押下状態の図である。実物の配置写真は[ヒットボックス製品・解説ページ](https://www.hitboxarcade.com/blogs/hit-box/hit-box-info-page)を参照。

### 236と214｜同じ三段階でも、使う指が異なる

![236 and 214 physical key states](https://silovar-uk.github.io/myessays/assets/arjun-leverless-visual-236-214.svg)

*Figure 1: Press → Add → Release. 青＝押している物理キー、右側＝ゲームが読む方向。*

**236＋P／K**: Middle finger presses Down; index finger adds Right; then release Down while keeping Right. Press P for 大義の巨腕 or K for 息吹の円筒. 派生の6＋Pまで含めて、まず1組の動作として覚えたい。The motion does not change just because the attack button changes. [Move list](https://sf6-genten.com/character/arjun)

**214＋K**は下→左下→左。Middle finger holds Down, ring finger adds Left, then middle finger releases Down. これで神気の巨巌。岩の出現位置はKの強度、タイミングはホールドで調整する。**The useful skill isn't only fast execution; it is reliable rock placement.** [GAME Watch](https://game.watch.impress.co.jp/docs/preview/2144359.html)

236が肩に化けるときは、直前に前歩きの6が残っていないか入力履歴を見る。Don't diagnose every wrong move as a timing problem. [Practical input-history example](https://hiyoko-lab.com/streetfighter6_hiyoko/traning_enter-history/)

### 623・323｜しゃがみ対空は薬指を使わずに作れる

Standard DP motion is 623＋P. But SF6 recognizes documented alternate routes, including **323 and 636**. These are alternate motion patterns rather than necessarily shorter ones. [Hit Box Arcade's manufacturer guide](https://www.hitboxarcade.com/blogs/hit-box/sf6-dp-shortcuts)

![Two physical methods for the same 323 input](https://silovar-uk.github.io/myessays/assets/arjun-leverless-visual-323.svg)

*Figure 2: Same game input, different finger demands. 1Pで薬指が難しければ上の方法から。*

**Method A — no ring finger / 薬指を使わない323**

① Hold Down+Right（3）。② Keep Down pressed, release only Right（2）。③ Repress Right and press P（3＋P）。これだけ。下を担当する中指は動かず、**人差し指が離す→戻す**だけ。左ボタンに触らない。The input history should show **3→2→3＋P**.

**Method B — opposing-direction neutralization / 左右相殺式323**

① Hold Down+Right（3）。② Add Left without releasing the other keys; Left and Right cancel, leaving Down（2）。③ Release Left and press P as Down+Right returns（3＋P）。こちらは右下を常に保持できる一方、**薬指で左を弾く**必要がある。Use it only if that motion is comfortable and consistent. [Japanese player explanation](https://note.com/0s4ke_games/n/n871e812d5b51)

結論は「Aの方が絶対に速い」ではない。**The better input is the one you can repeat under pressure without tension.** 1PではAが有力、2Pでは指の事情が逆転することを後半で説明する。

### 636｜前歩きからの肩は、さらに二本の指で済む

![636 vs standard 623 key-state sequence](https://silovar-uk.github.io/myessays/assets/arjun-leverless-visual-636.svg)

*Figure 3: Hold Right, tap Down, release Down.*

**636＋P**: Keep Right held（6）, add Down（3）, release Down and press P（6＋P）。動かすのは下の中指だけ。This is useful while moving forward or when an index-and-middle-finger motion is more reliable than a ring-finger tap. [Hit Box Arcade](https://www.hitboxarcade.com/blogs/hit-box/sf6-dp-shortcuts)

しゃがみを維持したい局面は323、前歩き中なら636、という整理が実用的。ただし**an input shortcut does not change the move's hitbox or invincibility**。アルジュンの厳酷な岩肩の強度別性能は別途確認する。[Arjun frame reference](https://sf6-genten.com/character/arjun)

313もメーカー資料に載るが、日常練習では323と636を先に安定させる。

### 63214｜半回転投げのコツは「指を増やす順」と「離す順」

![63214と22の押下状態を一段ずつ示した図](https://silovar-uk.github.io/myessays/assets/arjun-leverless-visual-grab-counter.svg)

*図4：筆者作図。63214は左右相殺を利用して標準方向列を作る。22は途中で下を離して無入力にする。*

鬼気迫る尋問＝**63214＋P**。入力を一気に回転として覚えず、次の五つの状態で覚える。

1. 人差し指で右だけ押す＝6。
2. 中指で下を追加＝3。
3. 薬指で左を追加。左右が相殺されて下だけ残る＝2。
4. **人差し指の右を離す**。左＋下が残る＝1。
5. **中指の下を離し**、左だけになったところでP＝4＋P。

**「右→下の順で離す」**がポイント。三本を同時に素早く押す練習よりも、2→1→4の後半をゆっくり作る練習が有効だ。なお、この一連の指の動きは標準63214を作るための一案。省略入力がゲームに受け付けられるという新しい主張ではない。

**技を出す場面**も重要。鬼気迫る尋問は近距離の投げで、相手に回復可能な体力が蓄積している状態ではダメージの扱いが変わる。岩を置く→ガードさせる→近づいて投げる、という状況を作ってから練習したい。[GAME Watchのコマンド投げ説明](https://game.watch.impress.co.jp/docs/preview/2144359.html)

### 22｜当身は「下・離す・下」。二回押すのであって押しっぱなしではない

**22＋強K** is a double Down input, not an extended hold. Press Down（2）, release it completely（5）, press Down+Heavy Kick（2＋強K）. 強K保持中のPは「倫理の崩壊」への派生。The crucial transition is the brief release between the two Down inputs. [Counter explanation](https://game.watch.impress.co.jp/docs/preview/2144359.html)

There is a theoretical SOCD idea: hold Down, tap Up to cancel it to neutral, then release Up to return to Down. That would create **2→5→2** under true-neutral mode. ただし**現行のアルジュンで、この物理入力が22として安定して成立するか未実測**。Treat it as a research idea, not a recommended main technique.

### SA1・SA2・SA3｜二回コマンドは「方向」と「ボタン」を分ける

![SA1とSA3の二回236、SA2の二回214を物理ボタンで示す図](https://silovar-uk.github.io/myessays/assets/arjun-leverless-visual-super.svg)

*図5：筆者作図。SA1＝236236＋K、SA2＝214214＋P、SA3＝236236＋P。SA1の最後はKである点に注意。*

**SA1「破壊の蛮声」**と**SA3「秩序の鬼神」**は、下→右下→右を二周。違うのは最後のボタンで、**SA1はK、SA3はP**。SA2「忘却の一槌」は下→左下→左を二周し、最後はP。SA3は残り体力の条件を満たすとクリティカルアーツ（CA）になる。[公式技表に基づくコマンド一覧](https://sf6-genten.com/character/arjun)

**練習順序**：まず236または214を一回だけ成功させる。次に攻撃ボタンを押さず方向を二回入力する。最後にP／Kを追加する。コンボからキャンセルする練習はその後。SAが出ない原因には「方向を取りこぼした」「ボタン種が違う」「キャンセルできる時間を過ぎた」「ゲージ不足」があり、それぞれ解決策が違う。

**OD（オーバードライブ）**の多くは同系統の攻撃ボタン2つを同時押しする。一方、**不撓の警衛にはOD版がない**と報じられているので、すべての技にODを想定して練習する必要はない。[電撃オンライン](https://dengekionline.com/article/202610/89267)

### 66・44、パリィ、ドライブラッシュ｜普通の入力ほど暴発を診断する

![66前ステップとパリィ・インパクトのボタン操作図](https://silovar-uk.github.io/myessays/assets/arjun-leverless-visual-common.svg)

*図6：筆者作図。前ステップは右→離す→右。パリィからのラッシュと、通常技キャンセルラッシュは使う場面が違う。*

- **66・44**：前・後ろへ同じ方向を二回。6→5→6のように一度離す。
- **中P＋中K**：ドライブパリィ。**強P＋強K**：ドライブインパクト。右手の同時押しが苦手なら単独で練習する。
- **パリィドライブラッシュ**：パリィからの66。**キャンセルドライブラッシュ**：キャンセル可能な通常技から66、または所定の方向＋中P＋中K。条件の違う二種類を一緒に覚えない。
- **ドライブリバーサル**：ガード中など特定状況で前＋強P＋強K。通常のインパクトと発動場面が違う。
- **特殊技・連係**：6＋強P「仁義の一刀」、6＋強K「頑強な跳舞」、中K→強K「規律の躍動」、強P→強P「不敵の調べ」、強P→強P→強P「鎮圧」、強P→強P→強K「追跡」、強K→強P「無情の拳」。方向が一つしか要らない技には複雑な相殺技術は不要。[アルジュン技表](https://sf6-genten.com/character/arjun)

## 人によって難しい理由｜薬指・左右差・疲労

**Finger independence varies.** 薬指を単独で動かそうとしても、中指がつられて動くことがある。A published hand-motion study found lower independence of the ring finger than the index finger. これは個人への能力評価ではなく、手指に連動性があるという一般的な生理学的知見だ。[Finger independence study](https://pubmed.ncbi.nlm.nih.gov/14973334/)／[Tendon connections](https://www.ncbi.nlm.nih.gov/books/NBK624301/)

![Finger-friendly leverless command choices](https://silovar-uk.github.io/myessays/assets/arjun-leverless-visual-fingers.svg)

*Figure 7: Easier movement routes when the ring finger becomes a bottleneck. 誰にとっても同じ最適解ではない。*

### 悩み1｜1P側の323で左を弾くと薬指がつる

**Change the motion before trying to force the finger.** 薬指の左弾きで323が崩れるなら、Down保持＋Rightのrelease/repressへ切り替える。Try ten reps of both and compare not only successful DPs, but also the effort and hand tension. 立ち姿勢から使うなら636も比較。ただし636はしゃがみ維持の代わりにはならない。

### 悩み2｜2P側になると前に歩けない・肩が出ない

On 2P, Forward is physical Left, often controlled by your ring finger. If you simply mirror Method A, 323 now requires rapid ring-finger release/repress—which can be frustrating. そこで使うのが**左右相殺版323を2P向けに反転する方法**。

Hold physical **Left+Down**（3）, tap physical **Right** with the index finger to create Down（2）, then release Right to return to Left+Down（3）, and press P. This keeps the ring finger held rather than asking it to tap quickly. **1P may favor index release; 2P may favor index tap.** 左右を機械的に鏡写しにするより、使いやすい指を主役にする。これは運指上の提案で、実際の成功率は各自トレモで確認する。

### 悩み3｜半回転投げの途中で動きが止まる

63214の五つ全部を一度に練習しない。まず**2→1→4（左＋下→左）**だけを10回。次に6→3→2を10回。最後に二つをつなぐ。途中の入力履歴が欠けるならPはまだ押さず、左の薬指を押し続けた状態で右と下を順に離す練習に戻る。

### 悩み4｜236のつもりが肩、肩のつもりが通常技

必要なのは指のスピードアップより、**入力履歴の直前2〜3行を見る**こと。前歩きの6が残っていれば昇竜型に化け得る。323なら↓が出ていない、または↓の行で先にPを押している可能性もある。[入力履歴の実例](https://hiyoko-lab.com/streetfighter6_hiyoko/traning_enter-history/)

### 悩み5｜ジャンプが暴発する／逆にジャンプできない

通常の上ボタンは親指担当。上と下を同時に押してしまうと、今回の設定では無入力となり、ジャンプできない。逆に下を先に離して上だけ残すと意図せず跳ぶことがある。**「下→無入力→上」と「下＋上→無入力」の違い**を履歴で確認する。大事な場面ほど上と下の同時押しを利用した裏技を後回しにする。

### 悩み6｜手が固まる・長くプレーすると精度が落ちる

押しっぱなしにできるボタンを毎回押し直さない。必要以上に深く・強く押す癖を減らす。手首は極端に反らさず、短い休憩を挟む。**痛み、しびれ、持続する違和感は「鍛えれば治るサイン」ではない**。一度中止し、続くなら医療専門家へ相談する。一般的な作業環境の手指負担対策でも、手首の中立位置と小休止が推奨されている。[米国労働安全衛生局（OSHA）](https://www.osha.gov/etools/computer-workstations/work-process)

### 薬指が苦手な人の練習法：難しさを分解する

- **30秒：押すだけ**。左ボタンを軽く押す。中指が一緒に動くかを観察。無理に独立させない。
- **30秒：押し足すだけ**。下を保持したまま左を追加し、1（↙）を作る。214・半回転投げの一部分。
- **30秒：離すだけ**。左＋下を保持し、下だけ離して4（←）へ移る。押すより離す方が難しい人もいる。
- **1分：選択**。薬指を使う323と、使わない323をそれぞれ試して「失敗が少なく、力まない方」を選ぶ。改善指標は速さより再現率。

## 破｜入力の失敗は、原因が六つに分かれる

Instead of asking “Why can't I do the move?”, ask **“Which key state was missing or out of order?”** 入力履歴があれば、失敗を分解できる。

- **Missing direction**：236で3が抜ける、63214で1が抜ける。速度を落とし、その遷移だけ反復。
- **Correct direction, no move**：button timing、技の硬直、キャンセル可否、ゲージを確認。
- **Wrong move**：直前の前歩きなど、older inputs still in the history を確認。
- **Unexpected SOCD**：Left+Right と Up+Down を単独で試して、設定を確認。
- **Only one side works**：Mirror the *game direction*, not necessarily the finger technique.
- **Fatigue errors**：短いセットで練習し、痛みを押して反復しない。

### 「最後の↘からPまで8F」をどう読むか

昇竜型の最終方向入力から攻撃ボタンまで**8F**という値は、[スト6初心者wiki](https://w.atwiki.jp/sf6begin/pages/128.html)などの攻略資料で報告されている。ただし、今回**2026年10月版のアルジュンで、その境界が公式に8Fと明記された資料や再現実測は確認できていない**。8Fは練習の参考値であり、厳密な確定仕様としない。

トレモでは、**「画面表示設定→入力履歴表示」**をON。入力履歴の数字はその入力状態が続いたフレーム数。最後の↘に切り替わってからPを押すまでの状態継続時間を確認する。例として↘が5F続き、そのあと↘＋Pになっていれば、Pを押す前に↘だけの状態が5Fあった。試行間で7F・8F・9Fを比較すれば受付境界の検証になる。ただし行の表示と内部受付の数え方の違い、通常技への化け、コマンド履歴の残存に注意する。[初心者wikiのトレモ説明](https://w.atwiki.jp/sf6begin/pages/53.html)

**重要**：8Fは「323全体を8Fで終える」という意味ではない。技の発生F、コマンド方向の受付、硬直中の先行入力猶予も別物。実戦での目標は8Fギリギリではなく、コマンドが完成したら余裕を持ってPを押せること。

## 再検証｜15分トレモメニュー

Enable **Input History** first. コマンド成立表示やフレームメーターは補助。When needed, slow Training Mode to 50% to check order before returning to match speed. [Training settings](https://w.atwiki.jp/sf6begin/pages/53.html) / [Practice guide](https://www.sf6-genten.com/beginner)

1. **0–3 min / Compare 323 methods**：1Pで薬指なし10回、左右相殺10回。Count successful moves and notice hand tension.
2. **3–6 min / 236 & 214**：各5回。Index+middle versus ring+middle. Kの強度で岩の距離も確認。
3. **6–9 min / 63214 & 22**：各5回。For grab, check 6→3→2→1→4. For counter, check 2→5→2.
4. **9–12 min / SA1, SA2, SA3**：各3回。Last button matters: SA1 ends K, SA2/SA3 end P.
5. **12–15 min / Randomized practice**：ジャンプ・ガード・設置の状況を記録再生。Choose the situation-appropriate move, then diagnose decision versus execution.

記録は三つだけ：①狙った技と実際の技、②欠けた方向・余計な方向、③次に変更する指の操作。**Nine successes in ten attempts** is a useful personal target, not an official benchmark.

## 離｜コマンドを「最短化」するより、局面を「省力化」する

Arjun uses rock placement, pressure and command grabs to build and cash out recoverable damage. 「一番短いコマンド」を探すだけでは、実戦の判断はよくならない。Instead, connect each **starting posture** to a reliable motion: crouching → 323, forward movement → 636, space control → 214, blocking opponent → 63214, anticipated attack → 22. These are practice hypotheses; spacing and opponent choices still matter. [Arjun's strategic overview](https://dengekionline.com/article/202610/89267)

**The key to leverless is not only how fast you press. It's knowing what you can keep held and what you should release.** 押し続ける指が決まれば、次の入力で動かす指が減る。薬指が難しければ、その指を使わない選択もできる。That is practical input optimization: adapting the controller to your hand, not punishing your hand until it obeys.

## 2P側｜左右は対称でも、指の負担は対称ではない

コマンドの数字は「キャラクターの前後」を表すので、2P側でも236や323という表記はそのまま。**物理キーだけ左右を入れ替える**。

- **2Pの236**：下→左下→左。中指＋薬指の操作になる。
- **2Pの214**：下→右下→右。中指＋人差し指を主体にできる。
- **2Pの323・右を弾く方式**：左＋下を保持→右を一瞬追加→右を離す→P。左右相殺でゲーム入力は3→2→3。
- **2Pの636**：左を保持→下を追加→下を離しP。前を担当する薬指が難しければ、上の323と比較。
- **2Pの63214**：物理左→左下→下→右下→右。指を離す順を丁寧に確認。
- **SAと22**：方向の前後は反転するが、P／Kの種類は変わらない。

「2P側も同じ指で鏡写しにする」が唯一の正解ではない。**物理的な指の使いやすさを基準に、操作方式を変えてよい**。
