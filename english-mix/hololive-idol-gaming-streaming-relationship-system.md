# アイドルなのに、why do they stream games all day?――ホロライブ入門
## バーチャルユーチューバー（VTuber）、streaming、company、fan culture、history and criticismを「そもそも」から理解する

「アイドル事務所」と聞いたあと、所属タレントの活動予定を開く。すると歌番組より先に、ゲーム実況（game streaming）、雑談、朝活、同時視聴、歌枠がずらりと並ぶ。数時間ゲームをして、翌日は誰かと雑談し、記念日になると三次元ライブ（3D live）で歌って踊る。かなり忙しい。だが、初見では役割がよく分からない。**アイドルなのに、why do they stream games all day?。**

さらに歴史をさかのぼると、もっと変である。ホロライブを運営するカバー（COVER）は、2016年に設立され、2017年2月に最初期の製品として仮想現実（VR）の卓球ゲーム「ピンポンリーグ（Ping Pong League）」を出している。同年9月に、ときのそらが活動を始め、12月に「ホロライブ」という名前の拡張現実（AR）ライブ視聴アプリが出た。いま世界的なバーチャルユーチューバー（VTuber）集団として知られる名前は、最初から「芸能事務所の名前」だったわけではない。

卓球からアイドルへ。しかも、そのアイドルはゲームをする。この変な曲がり方を真面目に追うと、ホロライブは「アニメ風のキャラクターが配信する事務所」という説明だけでは足りなくなる。配信者、キャラクター、技術、動画プラットフォーム、ファン、二次創作（fan derivative works）、音楽、物販、広告、rights clearance、制作会社が、毎日同じ場所で接続される仕組みだからである。

最初、私はこれを「巨大なIP operating system」と呼べば片づくと思った。実際、カバー自身もバーチャルユーチューバー（VTuber）の知的財産を育て、複数媒体展開（media mix）へ広げる事業を説明している。だが、歴史と失敗例まで調べると、その言い方も少し冷たすぎた。ホロライブの強さも、たびたび起きた摩擦も、知的財産そのものより**person-to-person、person-to-company、person-to-rights-holderのあいだを、キャラクター越しにどう結び続けるか**という問題に集まっていた。

## 1. そもそもバーチャルユーチューバー（VTuber）は「AI character」ではなく、personaをavatarで表現するstreaming formatである

バーチャルユーチューバー（VTuber）を初めて見ると、まず「これはアニメなのか、人なのか、人工知能なのか」というところで止まりやすい。答えを急ぐより、画面に何が重なっているかを分けると分かりやすい。バーチャルユーチューバー（VTuber）は、二次元・三次元のアバターを使い、動画投稿やライブ配信などを行うタレントの総称として使われる。少なくともホロライブを理解するうえでは、**「キャラクターの姿で活動する配信者・表現者」**と考えるのが近い。

画面上では、イラスト風の人物が口を開き、目を細め、身体を揺らす。その裏では、カメラや各種センサーが演者の表情や動きを読み取り、ライブツーディー（Live2D）や三次元モデル（3D model）へ反映する。カバーは2018年の配信アプリ更新時点で、スマートフォンの前面カメラによる表情認識（facial tracking）と、三次元・Live2Dのキャラクターへのリアルタイム（real-time）反映を説明していた。現在は自宅向けの仕組みだけでなく、スタジオで光学式モーションキャプチャー（motion capture）なども用いる。

ここで大事なのは、アバターが「人間を消す」道具ではないことである。むしろ声、間、笑い方、ゲームの判断、歌、雑談の癖といった人間的な差が、同じキャラクターデザインの形式を通ることで強調される。衣装や設定はフィクションでも、数時間の生配信を毎日続ければ、すべてを台本だけで作ることはできない。バーチャルとは「人間がいない」という意味ではなく、**人間の表現に別の身体を一枚重ねる技術**なのである。

この区別ができると、バーチャルユーチューバー（VTuber）を「新しいアニメキャラクター」とだけ見る説明も、「顔を隠した普通の配信者」とだけ見る説明も、どちらも半分になる。ホロライブが扱っているのは、キャラクターか人間かの二択ではなく、その二つが重なった状態を長期間運営する仕事である。

## 2. 「ホロライブ」という言葉は、アプリ、女性グループ、プロダクションの順に意味が広がった

初心者が混乱する原因の一つは、「ホロライブ」が一つのものだけを指していないことである。いま日常会話で「ホロライブ」と言うと、所属タレント全体や事務所そのものまで含めて呼ぶことが多い。しかし歴史上は、名前の用途が変化してきた。

2017年12月の「ホロライブ（hololive）」は、キャラクターの三次元映像を現実空間へ重ね、ライブを見たり撮影したりするスマートフォン向けアプリの名称だった。2018年4月、そのアプリは「スマートフォンでバーチャルユーチューバー（VTuber）になりきれる」配信側の道具へ改修され、専属バーチャルユーチューバー（VTuber）の募集へつながる。同年6月、ようやく女性バーチャルユーチューバー（VTuber）グループ「ホロライブ」が立ち上がる。

その後、男性グループのホロスターズ（HOLOSTARS）、インドネシア向けのホロライブインドネシア（hololive Indonesia）、英語圏向けのホロライブイングリッシュ（hololive English）などが増え、それらを束ねる上位名として「ホロライブプロダクション」が使われるようになった。2023年には新しい音楽・表現系統としてホロライブ・デバイス（hololive DEV_IS）が始まり、リグロス（ReGLOSS）、のちにフロウグロウ（FLOW GLOW）が加わった。

ただし、このmap itself is now in transition. 2026年9月7日、カバーは2027年の10周年へ向けたrenewalとして、従来のhololive、hololive Indonesia、hololive English、hololive DEV_ISといったregional / group-based brand structureを、順次one “hololive”として展開していく方針を発表した。9月30日時点ではofficial sitesに従来のcategoriesも残っており、naming systemはtransitionの途中にある。

したがって、「ホロライブ＝女性タレント全員」「ホロライブ＝会社」「ホロライブ＝プロダクション」のようにperfect synonymsとして固定すると、時期によってずれる。運営会社はCOVER、芸能組織はhololive productionというdistinctionを押さえたうえで、そのinternal brandsは2026年から“hololive”へintegrateする方向に動いている、と理解するのが現在は最も安全である。

この名称の伸び方は単なるbrand housekeepingではない。もともとtechnology productだった名前が、出演者の集団を指し、regional brandsを経て、再びglobal common nameへ広がろうとしている。**ホロライブの歴史は、technologyが主役だった会社で、人の活動のほうがforegroundedされ、最後にはregionよりculture itselfを前へ出そうとする歴史**でもある。

## 3. Game streamingは「アイドルらしくない寄り道」ではなく、relationshipを毎日updateする本体である

では最初の疑問へ少し戻る。なぜ歌って踊る人たちが、あれほど長くゲームをするのか。ここで「ゲームが人気だから」だけでは説明が浅い。ゲーム実況（game streaming）は、ホロライブにとって作品を完成させて見せる場というより、**タレントと視聴者がshared timeを過ごし、relationshipをsmall incrementsでupdateする場**として働く。

三次元ライブ（3D live）は特別である。新曲、衣装、照明、振付、映像演出が準備され、多くの視聴者が同じ時間に注目する。一方、普段の配信では「今日は何をするか」「この敵に勝てるか」「昨日の話の続きはどうなったか」という小さな出来事が積み重なる。大舞台が年に数回でも、雑談やゲームは毎日のように開ける。この時間差が、芸能人の「作品を見る」関係と少し違う親密さを作る。

カバー自身も、所属バーチャルユーチューバー（VTuber）がゲーム、カラオケ、雑談、collab streamなどを日常的に行い、そこから高品質なライブやイベント、音楽へ活動を広げる構造を事業説明に置いている。2026年6月時点で、ホロライブプロダクションは78名、動画共有サービスのユーチューブ（YouTube）の合計登録者数は9520万人、総再生回数は250億回、登録者100万人超のバーチャルユーチューバー（VTuber）は45名とされる。ここで重要なのは「巨大な数字」そのものより、その数字の基礎に日々の配信があることである。

試しに順序を逆に考えると分かりやすい。年に一度だけ豪華なライブをする、普段は何も話さないキャラクターがいたとする。技術的には「バーチャルアイドル」でも、現在のホロライブらしい文化はかなり薄くなる。逆に、日々の配信でrelationshipがaccumulateするからこそ、ライブの一曲、記念グッズのモチーフ、過去の発言を拾った冗談に意味が宿る。

だから、ゲーム配信（game streaming）はアイドル活動の合間ではない。**日常配信（everyday streaming）が「この人を知っている」という感覚を作り、その蓄積がライブ、音楽、物販を特別な出来事へ変える。** 「アイドルなのにゲームをする」のではなく、配信で関係を作る仕組みの上に、アイドル的な舞台が乗っているのである。

## 4. 歴史を一本につなぐと、「仮想現実（VR）会社がバーチャルユーチューバー（VTuber）へ転職した」のではなく、通信技術の主役が人へ移ったと分かる

ホロライブの歴史を年表として覚えるなら簡単である。2016年にカバー設立、2017年にときのそら、2018年にホロライブ、2019年にホロスターズ、2020年にインドネシアと英語圏、2023年に上場とホロライブ・デバイス。だが、年だけ並べると「会社が流行へ乗り換えた」という雑な物語になりやすい。

カバーの取締役・最高技術責任者である福田一行は、創業期に仮想現実の次世代基盤を探り、卓球ゲームを作ったあと、キズナアイの伸長やライブ配信市場を見て、仮想キャラクターをリアルタイム（real-time）配信できる基盤へ発想を移したと説明している。キズナアイは2016年12月に活動を始め、自らを「バーチャルユーチューバー（VTuber）」と名乗った先駆的存在だった。つまり、技術と表現者の市場がほぼ同時に立ち上がり、カバーは「仮想空間そのもの」から「仮想の身体で人が話すこと」へ焦点を寄せた。

ときのそらの活動開始は2017年9月。その後、アプリ、募集、グループ化を経て、2019年には音楽レーベルとホロスターズ、2020年には海外へ広がった。英語圏向けのホロライブイングリッシュ（hololive English）が始まった2020年9月以降、バーチャルユーチューバー（VTuber）は「日本語のアニメ文化を輸出する」だけでなく、英語圏の演者が英語圏のネット文化を使いながら、日本発のキャラクター形式を再解釈する場にもなった。

2023年3月、カバーは東京証券取引所グロース市場へ上場した。同年9月にはホロライブ・デバイスが始まり、従来の「期生」だけでは整理しにくい新しい活動軸を作った。2026年9月7日、ホロライブプロダクションは9周年を迎え、10周年へ向けた企画を始めている。

ここまでを見ると、卓球は黒歴史ではない。創業時から一貫していたのは「仮想空間でどうコミュニケーションするか」という問いで、途中から最も強い答えが「空間」ではなく「人」になったのである。**ホロライブの転換は、仮想現実を捨てたのではなく、仮想性の中心を場所から人格へ移した転換**と見ると筋が通る。
