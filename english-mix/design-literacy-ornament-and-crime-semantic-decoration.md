# 「装飾は犯罪」って、ほんまに“飾るな”という意味だったのか

デザイン史には、titleが強すぎて本文を読む前に結論を知った気になる文章がある。

**Ornament and Crime.**

装飾と犯罪。

Crime.

ちょっとbuttonにshadowを付けただけなのに、policeが来そうである。

Adolf Loosのこの有名なessayは、20世紀のModernismやFunctionalismを語るとき何度も引用されてきた。MoMAも1908年のessayとして紹介している。

So, did Loos really mean “never decorate anything”?

ここでLoos本人の建築を見る。

Villa Müller。

The exterior is restrained.

ところがinsideは、material、furniture、spaceの高低差、lightの扱いが濃い。プラハ市立博物館もLoosの住宅についてornament-free facadeを特徴として挙げる一方、drawing roomはsumptuousで、space / material / equipment / lightを組み合わせた設計だと説明している。

Outside: quiet.

Inside: rich.

「装飾をなくせ」という単純な覚え方が、いきなり怪しくなってきた。

## VISUAL MAP｜装飾を「ある / ない」で見ない

今日のmapを一枚にする。

```text
                 ORNAMENT
                    │
                    ▼
             What job does it do?
                    │
      ┌─────────────┼─────────────┐
      │             │             │             │
   UTILITY      LEGIBILITY    EXPRESSION     IDENTITY
   使う助け      読む助け       感情を作る      らしさを作る
      │             │             │             │
   state cue     grouping       mood          brand cue
```

今日のquestionは、

> Is decoration necessary?

ではない。

> **What job is this decoration doing?**

である。

## FACT｜Loosは「装飾」をculture・economy・laborの問題として攻撃した

Loosの『Ornament and Crime』は、ornamentを単なるtasteとして扱っていない。

彼は日用品へ付け加えられるornamentを、cultural development、labor、product lifespan、economyの問題と結びつけ、modern societyでは不要な装飾から離れるべきだと強く主張した。

MoMAのPaola Antonelliも、Loosのessayを、industrialization後のdesignがexcessive expressivenessやdecorationを抑制し、visual disciplineとfunctionalismへ向かった流れの代表例として位置づけている。

だから、

```text
ORNAMENT
↓
REMOVE IT
```

という理解が生まれるのも分かる。

But if we stop here, Loos's own spaces become awkward evidence.

## もう一歩やりすぎる｜装飾を全部ゼロにしたLPを想像する

Imagine an event landing page.

最初はこう。

```text
🔥 炎日 🔥

[ EVENT PHOTO ]

SPECIAL MATCH
━━━━━━━━━━━━
限定フード
限定グッズ
イベント

[ チケットを購入 ]
```

では、“ornament is bad”として全部取る。

```text
炎日

写真

限定フード
限定グッズ
イベント

チケットを購入
```

Calmer.

読みやすくなる部分もある。

But something else disappeared.

「祭りっぽさ」「特別な試合感」「この企画固有のtemperature」が弱くなった。

今度は逆に、decorate everything.

```text
🔥🔥 炎日 🔥🔥
✨ SPECIAL MATCH ✨
━━━━━━━━━━━━━━
★ 限定フード ★
★ 限定グッズ ★
★ イベント ★
🔥 [ チケットを購入 ] 🔥
━━━━━━━━━━━━━━
```

Too much.

全部がshoutingしているので、どこがimportantか分からない。

Extreme cases make the problem visible.

問題は「ornament exists」ではない。

**装飾のroleとdistributionが設計されていないこと**だ。

## Before → After｜「装飾を減らして」から一歩進める

### Before

> 装飾が多いので、もっとsimpleにしてください。

便利だけどdangerousな指示でもある。

受け手は“remove”をgoalにしてしまう。

### After

Audit one element at a time.

```text
炎のモチーフ
→ EXPRESSION：企画の熱量

色付きバッジ
→ LEGIBILITY：限定情報の識別

ボタンの影
→ UTILITY：操作可能性の補助？

独自パターン
→ IDENTITY：企画固有のvisual cue

キラキラ
→ ???
```

最後だけ説明できないなら、まずそこから疑う。

**Remove decoration by function, not by ideology.**

## RE-RESEARCH｜Loos本人の空間は、ぜんぜん「無味無臭」ではない

Back to Villa Müller.

プラハ市立博物館はこの住宅を、Loosの生涯にわたる住宅建築の探究を体現した重要作として紹介し、interior composition、detail、material、equipment、lightを重視している。

同館のLoos展資料では、drawing roomはしばしばsumptuousで最大の部屋となり、libraryやboudoirはよりintimateに設計されたと説明されている。

つまり、

```text
FACADE
ornament-free / restrained

          ≠

EXPERIENCE
empty / emotionless
```

Removing applied ornament does not remove experience.

Material, proportion, space, light, furniture can still carry expression.

現代UIでも同じ。

白背景だからminimalなのではない。

角丸を消したからfunctionalなのでもない。

**Expression can live somewhere other than decorative parts.**

## ここでは笑えない｜『Ornament and Crime』には危険な前提もある

このessayを、そのままmodern design principleとして持ち上げることはできない。

Loosはtattooをcriminalsや、当時の差別的な語彙で「degeneration」と結びつけた。MoMAはこの見方を明確にincorrectとし、tattooが持つrich social and aesthetic historyを無視したものだと批判している。

Canadian Centre for Architectureが所蔵するJuan José Lahuertaの研究紹介も、『Ornament and Crime』のlanguageがcriminal anthropologyやbioevolutionismと結びつき、women、Papuans、artists、criminalsなどを“primitive / degenerate”とみなすpseudo-scientific worldviewを含んでいたと整理している。

ここは、

> 昔の人だから仕方ない

では流せない。

**FACT:** このessayはModernist discourseへ大きな影響を与えた。

**FACT:** 同時に、現在では受け入れられないracist / pseudo-scientific assumptionsを含んでいる。

**INTERPRETATION:** 現代制作へ持ち帰るなら、“ornament is bad”という結論ではなく、added formが何のvalueを生んでいるか検証するattitudeの方が使える。

## 現代UIへ戻す｜「Semantic Ornament」という見方

ここからはpractical interpretation。

`Semantic Ornament`を、この記事では**meaningやroleを持ったdecoration**というworking labelとして使う。

Established academic taxonomyとして断定するためではない。

例えば、

```text
赤い縁取り
→ ERROR STATE

紙吹雪
→ SUCCESS / CELEBRATION

クラブ固有の斜線
→ IDENTITY

カード間の罫線
→ GROUPING
```

Visually, all of them may look like decoration.

でも実際にはinformationやemotionを運んでいる。

MoMAの『Talk to Me』が示すように、contemporary designではobjectsやinterfacesはfunctionだけでなくmeaningやpersonalityもcommunicateする。

すると、

```text
ORNAMENT
vs.
FUNCTION
```

というbinaryは苦しくなる。

Sometimes,

```text
ORNAMENT
CAN BECOME
FUNCTION
```

だからだ。

## そのまま使える制作・修正指示

> 装飾要素を一律にreduceするのではなく、それぞれがUTILITY、LEGIBILITY、EXPRESSION、IDENTITYのどのroleを担っているか確認してください。役割を説明できない要素から優先的に整理し、information hierarchyやoperabilityを妨げるornamentは弱めてください。一方、企画固有のemotionやbrand identityを担うexpressionまで均質化しないようにしてください。

Short version:

> **What job is this decoration doing?**

## #32 Memphisとの接続｜正反対に見えて、実は同じ問いをしている

#32ではMemphisを扱った。

Memphis asks:

> Can function alone explain design?

今日のLoosからは、

> Does adding expression automatically make design richer?

と問える。

```text
             LESS                         MORE
              │                            │
LOOS      不要な表現を疑う           意味ある素材・空間
              │                            │
MEMPHIS   機能だけを疑う             表現・文化・感情
              │                            │
              └───────────┬────────────────┘
                          ▼
                 WHAT IS IT DOING?
```

結局、量だけでは評価できない。

#32で増やしたEXPRESSIONというaxisを、#41ではauditする。

**Expression matters. And expression still needs a reason.**

## 30秒でできる観察｜一個だけ消してみる

今見ているwebsiteで、visual elementを一個選ぶ。

Color, line, shadow, pattern, border radius, background image. Anything.

頭の中で消す。

```text
REMOVE IT
   ↓
What gets lost?
```

「情報の区切り」→ LEGIBILITY。

「押せそう」→ UTILITY。

「楽しい感じ」→ EXPRESSION。

「このブランドらしさ」→ IDENTITY。

Nothing?

Then maybe it is removable.

## 次につながる概念｜Ornament as Information

次に面白いのは、ornamentをinformationとして扱うこと。

Pattern, texture, color, motionは、ただscreenをbusyにするだけではない。

They can carry category, state, hierarchy, culture, and brand.

次は、

**Where does information end and noise begin?**

という問いにつながる。

---

## 今日の中心命題

**Do not ask whether decoration is necessary. Ask what job it is doing.**

「装飾は必要か？」ではなく、

**この装飾は何の仕事をしているか？**

と聞く。

タイトルだけ見ていたとき、Loosは“the guy who said don't decorate”に見えた。

でも本人のarchitectureを見て、interiorを調べ、essayの危険なhistorical assumptionsまで追うと、same words look different.

装飾を消せばdesignが良くなるわけではない。

装飾を足せばrichになるわけでもない。

そしてdecorationだと思っていたものが、informationやemotionを運んでいることもある。

次にshadowやborderやpatternを見たとき、

「これはornament」と分類する前に、一回だけ止まる。

**Okay. What job is this thing doing?**

その瞬間、装飾は「ある / ない」の問題ではなくなる。
