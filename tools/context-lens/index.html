Context Lens

いま動いているページを、
AIが読める開発文脈に。

入力中の値、開いているメニュー、実行後のHTML。ページの状態を整理して、ひとつのテキストにまとめます。

外部送信なし 設定なしで使える 秘密情報をマスク

iPhoneのSafariに登録

  1. このページをSafariで開き、共有メニューからブックマークに追加します。名前は「Context Lens」にします。
  2. 下の「登録コードをコピー」を押します。
  3. Safariのブックマーク一覧で「編集」を開き、保存したブックマークのURLを消して、コピーしたコードに置き換えます。
  4. 調べたいWebページを開き、ブックマークから「Context Lens」を実行します。

登録コードを表示・手動コピー

パソコンではContext Lensを起動をブックマークバーにドラッグして登録できます。

いつもの操作は3つだけ

  1. 調べたいページで、Context Lensのブックマークを実行。
  2. 「AI用コピー」をタップ。
  3. ChatGPTなどに貼り付けて、相談内容を添える。

自動コピーに失敗した場合も、同じ画面にテキストが表示されます。「もう一度コピー」または長押しでコピーしてください。

調べたい範囲を選べる

  • 標準：ページ構造・現在の入力値・操作要素・HTMLを取得。
  • 詳細：構造化データや読み込みリソースを拡張。Storageの値は自分で選んだキーだけ。
  • 要素：対象をタップして、HTML・属性・位置・主要なCSSを取得。
  • 差分：「比較の基準を保存」→ページを操作→「差分コピー」。同じページ内の追加・削除・属性・入力値を比較。

取得する前に知っておきたいこと

パスワード、認証情報らしいキー、隠し入力を除外します。ただし、自動マスクは完全ではありません。本文や自由入力欄に含まれる個人情報は、AIに渡す前に確認してください。Cookieは読み取りません。取得内容は外部送信せず、ページを閉じると消えます。

別オリジンのiframe、閉じたShadow DOM、過去の通信のレスポンス本文、コンソール履歴は取得できません。大量の要素があるページでは件数・文字量に上限を設け、取得できなかった情報を明記します。比較対象の入れ替わった要素は追加・削除として扱います。

起動できない場合

通信障害や、ページ側のコンテンツセキュリティポリシー（CSP）によって外部スクリプトが拒否されることがあります。再読み込み後も起動しない場合は、そのページではブックマークレット版を利用できない可能性があります。

Safariショートカット版は未提供です。外部スクリプトを読み込むだけのショートカットを、CSPを回避できる方法としては案内しません。代わりにページの必要な文章を手動コピーし、画面のスクリーンショットとともに相談してください。
